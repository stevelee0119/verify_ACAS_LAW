# 검증 대상 문서 디렉터리

`scripts/verify_cli.py`와 "문서 검증 실행" 워크플로가 이 디렉터리의 문서를 읽는다.
비어 있으면 워크플로가 `scripts/make_sample_documents.py`로 예시 문서를 만들어 넣는다.

**실제 사건 문서를 공개 저장소에 커밋하지 말 것.** 의뢰인 비밀과 개인정보가 이력에 남는다.
실제 문서로 검증할 때는 비공개 저장소를 쓰거나, 웹 UI(`uvicorn apps.api.main:app`)에
업로드하는 방식을 쓴다.

예시 문서는 탐지 동작 확인용이며, 그 안의 판례번호·당사자는 실재 자료가 아니다.
