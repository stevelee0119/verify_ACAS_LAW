# TK-74 표준판례 표가 문서 이름 선별을 통과하지 못하면 색인되지 않아 인용 사건번호 조회가 돌지 않는다 (P2, 기능 공백, TK-71 후속)
- 유형: 기능 공백(P2). **회귀가 아니다.** 0.11.0(a8b2a7e)에서도 표는 색인되지 않았다(당시 원인은 문자 상한, TK-71).
- 발견: 평가 측, 릴리스 0.12.0 배포 직후 온라인 점검(2026-10-10, 서면9, run_23737ae77bd644aa, 보고서 commit 9c1b218).
- 작성: evaluator 2026-10-10

## 1. 증상
- 사용자 Drive 참고자료 폴더의 '판례' 하위 폴더에 표준판례 표(xlsx, 약 2.5MB)가 있다. 인벤토리에는 잡힌다(`files_by_type` `.xlsx` 1).
- 그러나 문서 단위 선별(`metadata_gate`)에서 `NAME_PATH_NOT_RELATED`(점수 0.133)로 `NOT_SELECTED_METADATA`가 되어 내려받지도 색인하지도 않았다. `case_table_stats`가 비어 있다.
- 서면9는 대법원 2022다29841 전원합의체 판결을 인용한다. 표가 색인되지 않아 TK-71의 사건번호 정확 조회·사건정보 대조(`reference_case_match`)가 이 실행에서 돌지 않았다.
- 이번 실행의 참고자료 색인은 2개뿐이다(이전 0.11.0 실행 37~40개). 배포로 추출기 버전(`drive-text-v5-case-table-resumable`)이 바뀌어 이전 캐시를 재사용하지 못했고, 선별된 파일만 새로 색인됐다.

## 2. 원인 (`packages/rag_engine/library.py`)
- `_sync_files`는 선별되지 않았고 현재 추출기 버전의 캐시도 없는 파일을 내려받지 않는다(295~297행, 326~328행 `NOT_SELECTED_METADATA`).
- 구조화 판례표를 문서 선별과 별도로 색인하는 경로가 없다. 정확 조회(`search_case_table`)는 표가 이미 색인돼 있을 때(`has_case_tables`)만 돈다.
- 표 파일 이름은 서면과 낱말을 공유하지 않는 것이 보통이다. 선별 규칙의 '<X법>표준판례' 제목 일치에도 해당하지 않는다(이번 파일 이름에는 법 이름이 없다).

## 3. 평가 측 자기 정정
- TK-71 4절 3은 "서면이 파일 이름 낱말을 공유하지 않아도 인용된 판례를 찾아야 한다. 색인 시점(첫 동기화 때 우선 색인 등)은 설계 메모로 정한다"고 요구했다.
- 설계 메모(`requests/62_tk71_structured_case_table_design.md`)는 색인 시점을 정하지 않았다. 평가 측은 수용 판정(7aecc51)에서 실제 표를 직접 동기화 대상으로 넣어 3,555행 색인을 확인했을 뿐, 선별을 거치는 실제 경로를 확인하지 않았다.

## 4. 요구
1. 참고자료 폴더의 스프레드시트 가운데 구조화 판례표(머리글·열 의미로 판별, 파일 이름 무관)는 문서 단위 이름 선별과 별도로 색인한다.
   - 시점·예산은 설계 메모로 정한다. 예: 동기화마다 표 후보(스프레드시트, 크기 상한 안)를 우선 확인하고, 시간 예산 안에서 이어 읽기(TK-71 경로)로 채운다.
   - 기존 예산(동기화 시간·내려받기 용량·파일 수)과 격리 추출·주입 검사는 그대로 거친다. 예산에 걸리면 사유를 남기고 다음 실행에서 이어 읽는다.
2. 표가 색인돼 있으면, 판례를 인용한 모든 문서에서 사건번호 정확 조회를 실행한다. 표가 아직 없거나 부분 색인이면 그 상태를 결과에 남긴다(예: 표 없음·색인 중·부분 색인 n행).
3. 일반 참고자료 발췌 선별은 바꾸지 않는다. 표를 색인했다는 이유로 표 조각을 문서 단위 대조 묶음에 넣지 않는다(TK-71 5절 범위 그대로).
4. manifest의 참고자료 진단에 표 후보별 상태(파일 id·색인 행 수·이어 읽기 진행·사유)를 남긴다.

## 5. 시험(합성 Drive 대역, 시험 설명에 합성임을 적는다)
- 양성: 서면과 이름 낱말을 공유하지 않는 판례표가 있을 때, 서면이 인용한 사건번호가 표에서 조회된다(일치·법원 또는 선고일 불일치·자료에 없음 각 1건 이상).
- 대조: 판례표 머리글이 아닌 스프레드시트는 색인 대상이 아니다. 이름 일치만으로 일반 자료를 선택하지 않는다는 기존 시험(`tests/test_drive_rag_relevance.py`)은 고치지 않고 통과한다.
- 예산: 표 색인이 동기화 시간 예산 안에서 멈추고 다음 실행에서 이어진다. 추출기 버전이 바뀐 뒤 첫 실행에서도 표가 다시 색인된다.
- TK-71 회귀 금지 시험 목록(TK-71 4절 6)을 고치지 않고 통과한다.

## 6. 수용
