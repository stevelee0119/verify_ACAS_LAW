## 2. 8D 범위
1. **(P1) 이름 키 아래 값의 fail-closed:** 사람 이름 키로 판정된 필드의 값은 이름 꼴로 판정되거나 이름이 아님이 확인되지 않으면 막는다. 직함·조사·띄어쓰기·복수 나열을 닫힌 낱말 목록으로 다루지 않는다.
2. **(P1) 이름 키 판정의 일반화:** 라벨 어휘 밖 사람 명사, 동의어, 붙여 쓴 영문 합성어, 약어 표기에서도 실명이 통과하지 않아야 한다.
3. **(P2) 평문 탐지 원복:** 구조화 키 판정용 영문 어휘가 평문 탐지(`LABELLED_PARTY_PERSON_RE`) 결과를 바꾸지 않아야 한다. 평문 탐지 결과는 시작(d20cde2)과 같아야 한다.
4. 리뷰 봇 지적 2건 처리(고치거나, 근거를 답하고 스레드 해결).

## 3. 설계 메모 먼저(필수 — 멈춤 규칙)
구조화 요청의 이름 키 유출은 같은 지표가 세 번째로 남았다(8차 키 변형 60/120, 8B 96/120, 8C 세트 0이나 새 모양 132/240). 8B·8C는 모두 **키 어휘 일치**에 기대었다. 그래서 첫 커밋으로 `docs/handoff/requests/32_round8d_design.md`(1쪽 이내)를 낸다.
- (a) 키 어휘를 늘리는 방식 밖에서, 어휘에 없는 키를 어떻게 다루는지
- (b) 사람 이름 키 아래 '이름 꼴이 아닌' 값의 처리 규칙(2절 1)
- (c) 구조화용 영문 어휘와 평문 탐지의 분리 방법(2절 3)
- (d) 예상 과차단 영향(평가 측 과차단 세트 6/28 기준)과 유출 위험
- (e) 시험 계획

평가 측은 PR에서 메모를 보고 '통하지 않을 이유'만 회신한다(비공개 입력은 공개하지 않는다). 회신을 기다리지 말고 구현을 계속하되, 회신이 오면 반영한다.
