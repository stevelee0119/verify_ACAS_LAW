## 3. 공통 작업 방식

**일반화 원칙(2차 지시서 3절을 그대로 유효로 하되 두 가지를 더한다).**
1. 표현이 아니라 **역할**: 기준일 / 변경 사건 / 적용 주장, 기초 사실 인정 / 면책 법리 / 범주적 결론, 표지 구조 / 식별자 / 의도.
2. 어휘는 의도·법리 **군집별로**, 일반 표현으로. 구분자·동사·어순·날짜 형식·띄어쓰기는 선택 사항.
3. 점수 합산(약한 신호 여러 개)과 필수 조건을 구분하고, 단일 신호만으로 HIGH를 내지 않는다.
4. 대조군을 먼저 쓴다. 오탐을 늘려 얻은 재현율은 인정하지 않는다.
5. **(추가) 열거하지 말고 체계를 따른다.** 조문 번호·구분자·낱말을 시험에서 본 것만 더하지 말고, 법·형식의 체계(헌법 제2장 전체, 위법성조각사유 전체, 임의의 짝 괄호)로 닫힌 집합을 만든다.
6. **(추가) 배치 불변.** 같은 정보를 줄바꿈·같은 줄·블록 경계·띄어쓰기만 바꿔 넣었을 때 결과가 같아야 한다. 새 규칙마다 배치만 바꾼 쌍을 시험에 둔다.

**막히면.** 보호 경로 변경·자료·정책 해석은 `docs/handoff/requests/`에 세 줄로 올리고 해당 묶음을 이어 간다.

**하지 말 것.** 시험 입력·정답지·티켓의 낱말을 코드에 추가, 기대값만 바꿔 시험 통과, skip, 기준선 하향, 시험 자료 직접 작성, 승인 대상 임의 구현, 보호 경로 수정, 강제 푸시, 줄끝 변경을 기능 커밋에 섞기, 출처 미확인 법령·판례 정보.
