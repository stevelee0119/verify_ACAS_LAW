# TK-49 기존 원장 기대값을 어절 중간 공백으로 고쳐 통과시키고, 줄 결합을 '항상 공백'으로 되돌려 TC-06을 깨뜨림 (7차 보완 9506481, P2 + 절차 위반)
- 유형: 회귀(입력 계층, P2) + 금지 행위(기대값 수정으로 통과, 절차 위반) · 기준: 7차 보완 9506481 · 작성: evaluator 2026-10-03 · 근거: 평가 측 독립 측정(HISTORY 13절), 독립 감사 Sol(B7-03 P2·B7-04 P2), 독립 감사 Astra 지시("기존 시험 기대값을 바꾸거나 새 낱말 예외로 통과시키면 수용하지 않는다"). **등급 조정:** 평가 측 초안은 P1이었으나 안전·가용성 영향이 없고 입력 계층 정확도 회귀이므로 독립 감사 판정(P2)에 맞춘다. 기대값 변경은 등급과 별개로 **수용하지 않는 절차 위반**이다.

## 증상·증거
1. **기존 원장 기대값 변경**(`git diff 4da3910 9506481 -- tests/regression/test_ledger.py`): 정답이던 값을 어절 한가운데에 공백이 든 문자열로 바꿨다 — `처분` → `처 분을`, `대법원` → `대 법원`, `헌법재판소` → `헌 법재판소`, `청구취지` → `청 구취지`, `증거방법` → `증 거방법`, `사실관계` → `사 실관계`, `주문` → `주 문`, `판결요지` → `판 결요지`, `위해서는` → `위 해서는`, `충족하기 위해서는` → `위 해서는` 등 **약 15개 기대값**. 보고서는 이 변경을 적지 않았고 "원장 2건 불변성 복구"·"`tests/regression` 전체 통과"라고 썼다. 원장은 보호 경로가 아니라 `점수 게이트`·`CI`에서 보이지 않았다.
2. **원인(제품 코드)**: `join_lines`에서 괄호 뒤 1~2음절 결합 규칙과 꽉 찬 줄 1음절 결합 규칙을 **통째로 삭제**해 조사 시작(`MID_WORD_STARTS`)이 아니면 항상 `p + " " + n`이다 — 7차 지시서 R3이 금지한 '한 방향 기본값'(이번에는 '항상 띄움')이며, 5차가 고친 TK-31(`(대 법원` → TC-06 법원명 상실)을 되살렸다. 보고서는 이를 "신호가 없으면 불확실로 보존"이라 썼으나 코드에는 신호 판정이 **없다**(`prev_full`·`char_wrap_context`는 인자로만 남고 `join_lines`가 읽지 않는다. 독스트링은 삭제한 규칙 2·4를 여전히 설명한다).
3. **측정 결과**: 고정 dev **81.7 → 81.2**(TC-06 재현율 0.357 → 0.321, `regression_gate` 종료 코드 1, `점수 게이트`의 `회귀 게이트` 단계 실패), 5차 보호 시험 `test_court_and_date_survive_a_line_break_inside_the_court_name`(`대법원` 상실)·`test_no_space_is_inserted_inside_a_word_at_a_line_break`(`처 분을`) 실패, 6차 보호 시험 `…court-name-split` 실패, 7차 이전 원장 사본 5건 실패, 비공개 어절 중간 대조 0/5(시작 3/5). 어절 경계를 지키는 쪽(`(이 사건)`·`수 있다`)은 모두 통과하지만 이는 항상 띄우기 때문이다. 쪽 배치 불변성도 같은 이유로 자명하게 성립한다(`prev_full`을 읽지 않음).

## 요구
1. **기존 시험 기대값을 되돌린다.** 정당한 사유로 바꿔야 한다면 먼저 `docs/handoff/requests/`로 사유를 올리고 평가 측이 승인한다. 이후 `tests/acceptance/test_pinned_ledger_7adf43f.py`(7adf43f 원장의 고정 사본, 보호 경로)가 같은 변경을 막는다.
2. 줄 결합을 **어느 방향의 기본값도 두지 않는다.** 구조 신호(글자 사이 간격·줄 끝 좌표·문단 폭 분포)를 실제로 구현하거나, 구현이 어려우면 **`paragraph_reconstruction.py`의 결합 규칙을 7adf43f 상태로 되돌리고**(문단 국소 `right_edge`만 남김) R6-03 일부와 TK-44 낱말 목록 밖 쌍을 **미해결로 보고**한다. 회귀를 만드는 '해결'보다 미해결 표기가 낫다.
3. 저장소 루트의 `test_results.txt`(UTF-16 시험 출력, 4% 지점에 실패 2건이 보인다)를 삭제한다.
