# TK-73 증거 목록 행의 설명 전체를 서증명으로 비교해 '같은 호증 번호 중복' A등급 오탐 (P2, 탐지, 기존 결함)
- 유형: 탐지 결함(P2). **회귀가 아니다.** 운영본(a8b2a7e)과 0.12.0(9c1b218)에 모두 있다. A등급 오탐이라 우선순위를 높게 둔다. TK-64와 같은 계열이다.
- 발견: 평가 측, 은퇴 봉인 세트 `sealed_20261010`을 개발용으로 옮긴 뒤 봉인 채점의 대조군 오탐 3건(A 3)을 조사(2026-10-10).
- 작성: evaluator 2026-10-10

## 1. 증상
- `tests/fixtures/retired_sealed/sealed_20261010/SD-01.pdf`(대조군, 정답 PASS)에서 `EVI.EVIDENCE_NUMBER_DUPLICATE`가 A등급으로 3건 나온다(갑 제1호증의 1·제1호증의 2·제3호증).
- 서면 구성: '가. 참고자료 목록' 아래 한 문단에 여러 행이 이어진다('갑 제N호증: 서증명, 위치 설명. 갑 제M호증: …'). 아래 절에 각 증거의 내용 문단이 같은 번호로 시작한다('갑 제N호증 서증명: 내용…').
- 실제로는 같은 증거(서증명도 같다)를 목록과 내용 문단에서 두 번 언급했을 뿐이다.
- 은퇴 세트 표준 환경 점수 15.2 / 0.302 / 오탐 3(대조군 3, A 3). 사용자 봉인 채점(운영본 a8b2a7e = 후보 0bf4ccc)과 같다.

## 2. 원인 (`packages/claim_engine/evidence_consistency.py`)
1. `_exhibit_lines`는 호증 번호 뒤 나머지 전체(날짜가 없으면 문단 끝까지)를 서증명(`name`)으로 잡는다. 목록 행은 '서증명, 위치 설명…', 내용 문단은 '서증명: 본문…'이 되어 같은 증거인데 `name`이 다르다.
2. `_numbering`은 공백만 지운 `name` 전체를 비교해 '서증명이 실질적으로 다르다'고 판단하고 A등급 중복으로 확정한다.
3. '참고자료 목록'은 목록 구역 제목으로 인식되지 않는다(`_EXHIBIT_SECTION_HEAD_RE`). 그래서 모든 행이 본문 구역 행이고, TK-64의 '목록 구역 번호의 본문 언급 제외'도 적용되지 않는다.

## 3. 요구
1. 중복 번호 판단은 서증명 자체를 비교한다. 서증명 뒤에 붙은 위치 설명·본문(쉼표·쌍점 뒤 서술 등)은 비교에서 뺀다. 방법은 설계 메모로 정한다(구분 기호 규칙, 서술 종결 판별 등).
2. 같은 번호의 두 행의 서증명이 같으면(공백·전각 정규화 뒤) 같은 증거의 반복 언급으로 보고 중복으로 확정하지 않는다.
3. 서증명이 실제로 다른 경우(목록 구역 유무와 무관하게)는 계속 A등급 중복으로 잡는다. TK-64 개정 1의 사례(목록 구역이 없는 서면의 본문 문장에서 같은 번호를 서로 다른 증거에 붙임)를 놓치지 않는다.
4. 목록 구역 제목 인식을 넓힐지(예: '참고자료 목록')는 설계 메모에서 정한다. 넓히면 TK-64의 구역 규칙 시험을 함께 통과해야 한다.
5. 은퇴 세트의 문장·서증명·사건 값을 규칙·시험에 넣지 않는다(`SD-` 하드코딩 점검).

## 4. 시험(합성 입력, 시험 설명에 합성임을 적는다)
- 오탐 제거: 목록 행('번호: 서증명, 설명')과 내용 문단('번호 서증명: 본문')이 함께 있는 서면에서 중복이 나오지 않는다. 가지번호·본번호 각 1건 이상, 3건 이상.
- 양성 유지: 같은 번호에 서로 다른 서증명을 붙인 경우는 계속 A등급. 목록 구역 있음·없음 각 1건 이상, 3건 이상.
- 시간: 새 분리 규칙은 반복 입력(수천 번) 시험 0.1초 이내.

## 5. 지시 사전 점검
- **평가 측 미실시.** 평가 에이전트 전환(2026-10-10) 전에 임시 패치 점검을 하지 못했다. 새 평가 세션이 임시 패치('서증명을 첫 쉼표·쌍점 앞까지로 비교')로 은퇴 세트 4종·고정 시험을 먼저 재고, 은퇴 a(`sealed_20261008`) 19.0이 떨어지지 않는지(TK-64 개정 1 사례) 확인한 뒤 배정한다.

## 6. 수용
- 은퇴 `sealed_20261010` 대조군 오탐 3 → 0(A 0), 재현율 0.302 유지 이상.
- 은퇴 `sealed_20261008` 19.0/0, `sealed_20261008b` 29.6/0, `sealed_20261009` 36.2/0, 고정 81.7/79.2/0 — 같거나 오름.
