# TK-69 FT 목 인용에서 가운뎃점으로 이은 목('가목·나목')을 인식하지 못한다 + 목 인식 정규식의 이중 공백 반복 (P3)
- 유형: 기능 공백(P3, 새 오탐 없음) + 정규식 효율(P3). 운영본 `main` a8b2a7e(0.11.0)에 있다.
- 발견
  - 가운뎃점: FT 구현 보완 수용 판정(2026-10-07, 판정서 'FT 구현 보완')의 후속 메모.
  - 정규식: 이 티켓 사전 점검 중 반복 입력 시간 점검(TK-66 뒤 정한 평가 측 규칙)으로 확인했다.
- 사용자 결정(2026-10-09, '1~6 권고대로'): TK-67과 같은 구현 묶음으로 낸다.
- 작성: evaluator 2026-10-09

## 1. 증상
1. **가운뎃점.** `packages/legal_engine/temporal_review.py`의 `SUBITEM_TAIL_RE`는 목 글자 뒤에 올 수 있는 문자를 정해 둔다(공백·문장부호·조사). 이 목록에 가운뎃점류(`·`, `・`, `ㆍ`)가 없다.
   - 평가 측 확인(Steve 114f8b3):

| 인용 원문 | `ITEM_SUBITEM_RE` 결과 |
|---|---|
| '제1호 가목·나목에 따라' | 일치 없음 → 조·항 경로로 돌아감 |
| '제1호 가목 및 나목' | 호 1, 목 '가'만 |
| '제3호 다목적 시설' | 일치 없음(정상) |

   - 결과: 목 단위 대조를 하지 않을 뿐 새 오탐은 없다. 목을 여러 개 든 인용은 첫 목만 본다.
2. **이중 공백 반복.** `ITEM_SUBITEM_RE`의 `호)\s*(?:제?\s*` 부분은 '제'를 생략할 수 있어 공백을 두 `\s*`가 나눠 가진다. 일치에 실패하면 공백 길이의 제곱에 비례해 시간이 든다.
   - 측정(평가 측, Python 3.11.15, 한 줄 `search` 1회): '1호' + 공백 n개 + 'x'
     - n 1,000: 0.018초
     - n 2,000: 0.077초
     - n 4,000: 0.283초
   - 지수적(TK-66)이 아니라 다항식이다. 입력이 인용 원문(`citation.raw_text`)으로 한정돼 실제 노출은 작을 것으로 본다. 다만 평가 측은 raw_text 길이 상한을 확인하지 못했다.

## 2. 요구
1. 목 뒤 문자 목록에 가운뎃점류(`·`, `・`, `ㆍ`)를 더한다. '다목적'처럼 목 뒤에 낱말이 이어지는 경우를 배제하는 기존 동작은 유지한다.
2. 한 인용이 든 목을 모두 읽는다: '가목·나목', '가목 및 나목', '가목, 나목', '가목부터 다목까지'.
   - 대조는 든 목들의 본문을 합친 범위로 한다.
   - TK-62 규칙을 지킨다: 어느 판본에서든 목 단위 VERIFIED가 있을 때만 '부존재' 판본을 CONTRADICTED로 둔다.
3. 공백 반복 모호성을 없앤다(예: `\s*(?:제\s*)?`). 반복 입력 시간 시험을 둔다: '1호' + 공백 수천 개 등 입력에서 0.1초 이내.
4. 시험(합성, 시험 설명에 합성임을 적는다)
   - 양성 3건 이상: 가운뎃점·'및'·범위 표기
   - 대조 3건 이상: '다목적'·'항목'·'품목'처럼 목이 아닌 낱말, 호 없이 '가목'만 있는 경우
   - TK-62 회귀 시험 유지
5. 서면의 문장·조문 번호에 맞춘 규칙을 넣지 않는다.

## 개정 1 — 평가 측 자기 정정(2026-10-09, PR #56 판정)
- 1절 표는 `ITEM_SUBITEM_RE`를 **문장 전체**에 대고 잰 결과였다.
- 실제 파이프라인의 입력은 인용 추출기가 만든 `citation.raw_text`이고, 이 값은 첫 목에서 끝난다(예: '…제1호 가목'). 그래서 기준 코드도 실제 경로에서는 첫 목('가')을 이미 인식했다.
- 이 티켓의 실제 공백은 '가목·나목'·'가목 및 나목'·'가목부터 다목까지'처럼 **둘째 목 이후를 실제 경로에서 읽지 못하는 것**이다.
- 요구 2를 다음으로 구체화한다.
  - 인용 뒤에 이어지는 열거·범위를 실제 경로에서 읽는다.
  - 파이프라인 경로 시험(`extract_citations` → `version_outcomes`)으로 단언한다.
  - 본문을 읽으면 창에 상한을 두고 이중 공백 모호성을 정리한다.
