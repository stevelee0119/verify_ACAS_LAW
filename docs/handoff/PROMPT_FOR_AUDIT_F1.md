# F1 독립 감사 의뢰서 — 검토 화면 1단계(AI 탭 축소·배정표) 병합 직전 점검 (감사 에이전트, 읽기 전용)

작성: 평가 에이전트(claude-code) 2026-10-04 · 근거: F1 병합 게이트 G8([7차 지시서 2절](PROMPT_FOR_STABILIZATION_ROUND7.md)) · 대상: PR #13 `antigravity/f1-review-screen`
이 문서는 구현 측과 평가 측 **어느 쪽의 주장도 그대로 믿지 않고** 직접 재현해 확인하는 일을 정의한다. 아래 전체를 그대로 붙여 넣어 쓴다.
**사용자 확정 결정은 감사 기준이다.** 이행 여부만 보고, 결정 자체에 대한 의견은 보고서의 "의견이 다른 점"에만 적는다(결함 수에 넣지 않는다).
- 개인정보: 자동 가림 **보장 대상은 연락처·주민등록번호**, 성명 등 그 밖의 항목은 보조 기능(업로드 안내·확인으로 사용자 처리). 보조 기능 수치는 참고로만 적는다.
- F1은 **화면·배정 변경**이다. 탐지·채점·개인정보 엔진은 바꾸지 않는다(점수·probe 전후 동일). 새 `rule_id`·새 탐지 금지.
- F1 범위: AI 탭을 'AI 작성·보안 진단'으로 축소, 97개 `FindingType`의 화면 배정표(`packages/common/finding_category_map.py`)와 `GET /api/finding-categories`, 판례 인용표·RAG·추가 관련 법조문을 '확인할 항목' 임시 섹션으로 이동, HIGH 이상 보안 항목 안내 배너. F2(`review_items`)·FT·F3는 범위 밖.

## 0. 규칙
1. 제품 코드·시험·평가 도구·`.github/`·`docs/scorecards/`를 수정하지 않는다. 커밋·푸시·배포하지 않는다. 산출물은 보고서·재현 스크립트·결과 파일이다.
2. 서술·점수·커밋 메시지는 주장이다. 직접 재현한 것만 사실로 적고, 재현하지 못한 것은 "확인 못 함"으로 적는다.
3. **대상을 SHA로 고정한다.** 비교 기준: `Steve_ACASiaLAW` a986f67(= 릴리스 0.10.0 `main` 22ca134의 제품). 대상: PR #13 head 중 `Steve_ACASiaLAW` a986f67을 병합한 SHA(사용자가 알려 준다). 대상 SHA와 a986f67의 차이 파일 목록부터 적는다.
4. 시험 실패를 (a) 제품 회귀 (b) strict XPASS (c) 환경 사유 (d) 시험·도구 오류로 나눈다. 기준 SHA의 알려진 미해결(strict xfail: TK-19·20·26·34·44·49·55·56)은 기대 집합이다.
5. 같은 입력·같은 환경의 전후 비교만 증감으로 쓴다. 오프라인 측정은 AI 작성 판별·공식 DB·Drive 대조를 재지 못한다.

## 1. 재현 환경
Linux, Python 3.11, 한국어 OCR(tesseract) 설치, `LV_ALLOW_NETWORK=0`, 외부 키 제거, 임시 데이터 경로. 브라우저 시험은 Playwright Chromium. 환경이 다르면 적는다.
