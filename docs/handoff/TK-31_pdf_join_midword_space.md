# TK-31 입력 계층: 줄 결합이 어절 한가운데에 공백을 넣어 판례 메타데이터를 잃는다
- 유형: 회귀(입력 단계) · 기준: 4차 e6b58fd 대 5차 c223f7b · 작성: evaluator 2026-10-03
- 근거: 독립 감사 Astra 5차 F2 + 평가 측 재현(TC-06). **TK-22 3절의 경고가 현실이 됐다**: "애매하면 항상 공백으로 고치면 글자 단위 줄바꿈 서면(`(대`/`법원`, 0.8.x 회귀 TC-06)이 되살아난다."

## 증상
- 고정 시험 TC-06(PDF)에서 줄 끝 `(대`와 다음 줄 `법원`이 `(대 법원`으로 합쳐진다. 4차는 `대법원 2007. 12. 21. 선고 2006두16274 판결`을 법원명·선고일과 함께 추출했으나 5차는 `2006두16274 판결`만 남기고 `court`·`decision_date`가 비어 있다. **평가 측 재현**(같은 PDF, 두 코드): 4차 court `대법원`·날짜 `2007-12-21`, 5차 둘 다 없음.
- 어절 중간에 공백이 끼는 다른 사례도 같은 PDF 블록에서 확인했다: `어떠한 처 분을`, `전부에 대하 여`(4차에는 없던 공백). 인용만이 아니라 모든 후속 단계(주장 추출·검색·참고자료 대조)의 입력이 영향을 받는다.
- 고정 시험 dev 종합 **81.7 → 81.2**(평가 측 재현, Astra와 일치), TC-06 문서 재현율 0.357 → 0.321. holdout은 79.2로 같다. **기존 probe 12종은 이 하락을 보지 못했다**(278/280 그대로, 평가 측 회귀 게이트가 문서별 성적표 비교를 하지 않았다 → 평가 측이 게이트를 고쳤다).
- 비공개 변형 4(평가 측, 저장소 밖)의 글자 단위 줄바꿈 변형에서 이메일·생년월일이 줄 끝에서 갈라질 때 마스킹이 실패하고(폭 36: PII-5·PII-7, 4차도 같음), 폭 36(CIT-1·2)·폭 56(CIT-2)의 법원 판결 인용이 실패한다. 줄 결합의 같은 결함군이다.

## 원인(코드 읽기)
- `packages/document_engine/paragraph_reconstruction.py`: 줄 결합의 **기본값이 공백 한 칸**이고, 공백 없이 잇는 판단은 `MID_WORD_STARTS`(조사·어미 목록 `은, 는, 을, 를, 의, …`)에만 의존한다(Astra 145행 부근 기본 동작, 평가 측이 목록 확인). 목록 밖의 어절 중간 줄바꿈(`대`/`법원`, `처`/`분을`)은 공백이 들어간다.
- **같은 파일에 평가 자료 표식 분기**가 있다(56행): `^\s*(?:HO-\d+|TC-\d+|검증\s*프로그램|홀드아웃용|가상\s*문서).*$` — 시험 문서(홀드아웃·TC)의 바닥글을 알아보는 제외 규칙이다. TK-33.

## 요구(일반 구조로)
1. **단어 경계 판정을 조사 목록에서 구조 신호로 옮긴다**: 줄 끝이 오른쪽 여백까지 찼는지, 줄 폭 분포(문서·쪽 전체 증거), 글자 좌표의 간격(공백 글리프 유무·글자 사이 간격), 원래 공백의 존재, 줄 끝 글자와 다음 줄 첫 글자의 결합 가능성을 쓴다. 글자 단위 줄바꿈 서면과 어절 단위 줄바꿈 서면 **둘 다**를 통과해야 한다(한쪽 기본값으로 고치면 다른 쪽이 깨진다).
2. 인용 추출기가 정규화 텍스트와 원문 위치(span)의 대응을 유지해야 한다. **특정 `대법원` 문자열만 붙이는 수정은 금지**다(다른 법령명·고유명사에 같은 결함이 남는다).
3. 불확실한 경계는 두 후보를 모두 보존하는 방식(공백 있음·없음 둘 다 질의)을 검토해 요청서에 의견을 적는다(불확실성 단조 원칙).
4. 5차에서 해소한 것(실제 Google Docs PDF의 규정 인용 문장 1개 복원, 청구 70→47, 검증 대상 17→19)은 **유지**한다(`test_case9_real_pdf.py`가 이제 일반 회귀 시험이다).
5. **PDF 폭 40의 case8 INJ-1은 아직 누락**이다(양쪽 모두). 구현 측 완료 보고의 "KNOWN_OPEN 10건 전수 해소"는 사실과 다르다(9건 해소 + 1건 잔여, `test_layout_invariance_pdf.py`가 잔여 1건만 KNOWN_OPEN으로 둔다). 해소하거나 미해결로 명시한다.
6. 같은 서면의 **빈 줄이 줄마다 낀 txt**(`txt-word-44-blank`)와 **docx 안의 수동 줄바꿈(Shift+Enter)** 변형에서 인젝션 표지(INJ-1)와 법원 판결 인용(CIT-2)이 실패한다(평가 측 변형 4, 4차·5차 모두 같은 항목 실패). 입력 형식·배치 불변의 같은 요구다.
