## 0. 정정(2026-10-04, 평가 측 오류 — 이 절이 1~7절보다 우선한다)
평가 측 측정 일부가 system 위치를 실제 라우터와 다르게 넘겼다. 실제 라우터는 system 앞에 `SYSTEM_BASE`·역할 줄을 붙여 검사하고, 원본 system은 `_original_system`으로 따로 넘긴다. 실제 라우터 경로로 다시 잰 8D(a7bd8bd) 값과 바뀌는 지시는 다음과 같다.
- 1.1의 '이름 키 아래 값 0/144·0/168'은 **user 위치에서만** 맞다. **system 위치에서는 30/144·38/168이 공급자에 도달한다.** 값 fail-closed(`_person_name_value_paths`)가 원본 system 경로에 적용되지 않기 때문이다(TK-55 6절).
- 1.2의 값도 바뀐다: 과차단 세트 14 → **12/28**, 비인명 낱말로 시작하는 사람 키 72 → **66/72**. 그리고 **키 변형 세트도 12/120**으로 기준(0)을 넘는다(system 위치).
- **2절에 범위 한 가지를 더한다:** (P1) 이름 키 아래 값의 fail-closed가 원본 system 경로(`_original_system`)에도 같게 적용되어야 한다. 키 변형 세트 0/120 회복도 수용 조건이다.
- **시험 방식:** 새 시험은 `inspect_request` 단독 호출이 아니라 실제 `LLMRouter.run`(가짜 공급자) 경로로 user·system 두 위치를 확인한다. 기존 평가 측 시험 `test_structured_request_privacy.py`의 `_route` 방식과 같다.
- 이미 설계 메모나 구현을 시작했으면 메모에 이 범위를 덧붙이고 보고서 2항에 적는다.

아래 전체를 Codex 작업 설명에 붙여 넣는다. 저장소 루트의 `AGENTS.md`도 함께 따른다.

### 1.2 불승인 사유
| # | 지표 | 8C | 8D | 기준 | 성격 |
|---|---|---:|---:|---|---|
| 1 | 정상 구조화 요청 과차단(평가 측 세트) | 6/28 | **14/28** | ≤ 6 | P2 |
| 2 | 비인명 낱말로 시작하는 사람 키의 실명 통과(새 입력) | 0/72 | **72/72** | 0 | **P1 회귀** |
| 3 | 이름 접미가 없는 역할 명사 키의 실명 통과(새 입력) | 144/144 | 144/144 | — | P1 잔여 → **알려진 미해결로 고정**(3절) |

- **1번 원인:** 이름 키 아래 값은 비인명으로 확인될 때만 통과한다. 그런데 확인 근거가 접두·접미 **낱말 목록**이라, 목록 밖의 기관·행정청·직무 표현이 막힌다. 새로 막힌 평가 측 세트 4건(× user·system)이 이 유형이다.
- **2번 원인:** 비인명 머리 판정을 '정확 일치'에서 '앞부분 일치'로 바꿨다. 이 판정이 사람 라벨 확인보다 먼저 돌아, 비인명 낱말 + 사람 라벨로 된 키 전체를 비인명으로 본다.
- 평가 측 설계 메모 회신 1·2번에 대한 반영 여부가 보고서에 없다.
- **평가 측 정정:** TK-54·8D 지시서의 유형 설명이 구체적이어서, 8D의 키 접미 목록이 그 설명과 거의 그대로 겹쳤다. 그래서 그 부분의 개선은 일반화 근거로 약하다. 이번 지시서의 유형 설명은 일부러 추상적으로 적는다.

## 2. 8E 범위(좁게)
1. **(P1) 2번 회귀 복구:** 사람 라벨이나 사람 이름 필드 형태를 포함한 키는 앞에 다른 낱말이 붙어도 사람 키로 판정되어야 한다. 비인명 판정은 사람 신호가 없는 키에만 적용한다. 수준은 8C와 같아야 한다.
2. **(P2) 과차단 회복:** 평가 측 과차단 세트 ≤ 6/28. 비인명 근거를 낱말 목록에 기대지 않는다. 방법은 설계 메모로 정한다(예: 근거의 종류를 구조로 정하거나, fail-closed를 적용하는 키의 범위를 신호가 강한 사람 키로 한정하는 등).
3. **유지:** 이름 키 아래 값 fail-closed(1.1), 평문 탐지 불변, 영문 구조화 어휘 분리.
4. **하지 않는 것:** 키 신호가 없는 유형(1.2의 3번)을 위해 키 판정을 더 넓히는 것. 이 유형은 3절대로 알려진 미해결이다.
