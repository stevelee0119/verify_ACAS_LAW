## 증상·증거
1. **기존 시험 새 실패 2건**(시작 통과 → 4da3910 실패): `tests/regression/test_ledger.py::test_r2_tk31_char_and_word_wrap_mix`, `::test_r2_tk31_google_docs_pdf_19_patterns`(문자열 쌍 19개 중 6번). `"요건을 구비하기 위" + "해서는 증명이 필요하다."`(prev_full=True)가 `위 해서는`으로 갈라진다 — `STANDALONE_WORDS`에 `위`를 넣어 `(위|계약)`을 맞추자 `하기 위|해서는`이 깨졌다. 같은 유형의 두 방향 충돌이 **낱말 하나로** 돌아온 것이다. 구현 보고서에 이 두 시험의 실행 기록이 없다(지시서 R5·5절: 커밋마다 `pytest -q tests/regression`).
2. **낱말 목록으로 구현**: `PAREN_DETERMINERS`(8개: 이·해당·위·본·그·저·동·각)와 `STANDALONE_WORDS`(18개: 그·이·저·위·본·각·동·해당·및·또·더·법·한·두·세·네·몇·매). 7차 지시서 R3은 "글자만으로 구별되지 않는 경계는 **기본값으로 확정하지 않고 레이아웃 신호로** 결정하며 신호가 없으면 불확실로 보존"을, 3절 3은 "예외 낱말 목록 대신 구조"를 요구했다. 평가 측 비공개 변형(저장소 밖) 결과: 괄호 뒤 관형어가 **목록 밖**(`당해·상기·아래·다음·별지·현행`)이면 **0/6**, 꽉 찬 줄 끝 1음절 어절이 목록 밖(`수·바·중·후·외·간·전·내`)이면 **0/8**(시작과 같음), 목록 안 변형은 4/4(시작 0/4). 어절 중간 분절 대조 5건은 시작 3 → 4da3910 2(위 1건 회귀).
3. **쪽 배치 의존이 남음**: `is_char_wrap_page`는 없앴으나 오른쪽 끝 `right_edge`는 여전히 쪽 전체 블록의 `x1` 분포에서 구한다(`reconstruct_page_blocks`). 같은 3줄 문단(`…할 수 | 있다고 … | 없다는 …`)이 쪽의 **다른 꽉 찬 줄이 0~1줄이면 `수없다는`, 2줄 이상이면 `수 없다는`**으로 달라진다(시작은 항상 같은 값으로 틀렸다). 구현 보고서의 "배치 불변성 확립"은 평가 측 보호 시험의 입력(`그 사람`, `그`가 목록 안)에서만 성립한다.

4. **독립 감사 추가 사례(A7-03, 평가 측 재현):** `법|률`→`법 률`, `세|종시`→`세 종시`, `(이|행)`→`(이 행)`이 **시작에서는 정답(붙임)** 이었고 4da3910에서 틀린다. `(한|종류)`→`(한종류)`는 시작·4da3910 모두 오류. 감사는 실제 2쪽 PDF에서 같은 글자·좌표의 문단이 둘째 쪽에 별도 문단이 있을 때 `구분하여`/`구 분하여`로 달라지는 것을 `parse_document` 경로로 재현했다(평가 측은 블록 수준 재현). **텍스트만으로는 `법|률`(붙임)과 `이 사건에서 법|적용`(띄움)을 가를 수 없다** — 낱말 사전도 또 하나의 목록이므로 글자 간격·줄 끝 좌표 같은 **레이아웃 신호**가 필요하고, 시험은 문자열 쌍이 아니라 실제 PDF(글자 좌표) 경로여야 한다. 폭 40 case8 INJ-1은 해소하거나 잔여 위험 문서로 보고한다(7차 보고에 없었음).

## 요구
1. 회귀 원장 2건을 복구한다. `위`를 목록에서 빼는 것으로 끝내지 말고, **같은 경계를 줄 끝 위치·글자 간격·문단 폭 분포로 판정**한다(R3 원문). 신호가 없는 경계는 `(위 계약)`·`(대법원)`처럼 확정하지 않고 불확실 표시를 보존하거나(텍스트 대응 유지) 양쪽 후보를 남긴다.
2. `right_edge`·`prev_full` 판정도 **문단의 줄들에서만** 얻는다. 같은 문단이 쪽의 다른 줄 수에 따라 다르게 결합되지 않게 한다.
3. 보존: 실제 Google Docs PDF 청구 47·검증 대상 19·제22조 문장 1, TC-06 법원명·선고일, 합성 PDF 폭 변형 9건, R6-03 보호 시험 XPASS 유지.
