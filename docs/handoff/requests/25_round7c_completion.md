## 4. 원본 이행 제안 정정 (0o444 vs 0o400)
7B 보고서에서 제안한 일괄 `chmod 0o444` 적용은 `packages/common/storage.py`의 소유자 읽기 전용(`0o400`) 계약을 훼손할 수 있는 잘못된 제안이었습니다.
* 데이터베이스 백업이나 설정 파일 암호화 교체 등 **수정이 필요한 순간**에는 임시로 쓰기 권한을 부여하되, 작업 완료 후 최종적으로는 **`chmod 0o400`**으로 원복하여 엄격한 권한을 유지해야 합니다.
* Python 내에서는 `os.access` 등을 통해 실행 사용자와 프로세스의 실제 권한 유무를 검사해야 하며, 기동 점검 및 최종 권한 이행은 시스템 관리자(또는 배포 스크립트) 단에서 책임지고 수행해야 합니다.
