# 8F-1 설계 메모 — 구분 기호가 줄바꿈에 붙은 주민번호

정규화 뷰와 원문 위치 매핑은 그대로 둔다. 원본 span에 줄바꿈이 있을 때 기존 fail-closed 조건을 풀 수 있는 경우를 좁힌다. 주민번호 표지가 없더라도 줄바꿈 바로 옆에 Unicode `Pd` 대시 또는 NFKC 후 하이픈이 있는 경우에만 통과시킨다. 기호 없이 줄을 넘는 후보는 계속 거부한다.

하이픈 인접성은 원문 span에서 확인하므로 정규화가 구분 기호와 줄바꿈을 합쳐 버려도 조건이 명확하다. 길이·자리 패턴, 기존 법률 식별자·법인 문맥 가드는 바꾸지 않는다. 새 시험은 합성 주민번호 두 방향(기호 앞·뒤 줄바꿈)을 가짜 공급자를 둔 실제 `LLMRouter.run`으로 user, system, 구조화 입력에서 검사하고, 무기호 줄넘김은 계속 탐지하지 않는지와 사건번호·날짜·금액 대조군을 확인한다.
