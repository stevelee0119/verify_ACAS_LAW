# TK-24 설계 메모 — 법정 규정의 범주적 적용 배제

평가 측 회신 전에는 탐지 코드를 작성하지 않는다. 대상 파일은 `packages/legal_engine/claim_review.py`이며 기존 TK-20 군집과 TK-45 절·극성 분석을 재사용한다.

**방법.** 적용 배제 대상은 닫힌 집합으로 제한한다: 법정 기간(소멸시효·제척기간·제소기간·불변기간), 법률상 성립 요건, 면책·책임한도 규정. 조문 번호는 트리거로 쓰지 않는다. 작성자가 단정한 결론절의 배제 서술어에 이 대상이 걸리고, 범주적 한정(일체·전면·무조건·어떠한 경우)도 같은 결론에 걸리는지 확인한다. 근거절은 정의·형평·자연법·인도주의, 다른 제도의 유추·준용, 상위 규범 유형으로 분류하고, 인과·양보 등 절 관계로 결론과 연결한다. 대상·근거·범주 표현의 문단 내 동시 출현이나 고정 거리만으로 판단하지 않는다.

**요건과 예외.** 같은 주장 단위에서 법정 예외의 요건 및 충족 사실, 이를 뒷받침하는 법령·판례가 배제 결론에 연결되는지 검사한다. 대상 규정 자체의 인용은 예외 근거가 아니다. 시효 중단·정지 등의 정확한 법정 사유를 원용한 주장은 알리지 않는다. 상위 규범에 따른 배제도 구체적 근거와 적용 논증이 있으면 알리지 않는다. 무관한 인용이 경고를 지우거나, 예외 이름만으로 면제되지 않게 한다. 근거의 정확성·연결 여부가 불명확하면 확정적 위법 판단 대신 기존 요건 확인 흐름으로 남긴다.

**일반화와 과탐 위험.** 숫자·당사자·사건 문장과 연결 낱말의 고정 위치는 사용하지 않는다. 주장자, 대상-서술어 관계, 부정·인용·상대방 주장·재반박의 범위를 먼저 판정한다. 법정 규정이 배제되지 않는다는 결론, 상대방 견해 소개, 개별 사안의 예외 적용과 범주적 배제를 분리한다. 기존 `NO_BASIS_REMEDY` 등과 별도 대상의 배제 주장만 추가해 중복 경고와 정상 항변 과탐을 막는다.

**시험 계획.** 구현 회신 후 합성 양성 5건 이상: 기간×정의, 다른 기간×유추, 소송 기간×형평, 성립 요건×자연법, 책임한도×상위 규범의 근거 없는 전면 배제. 합성 대조 3건 이상은 실제 법이 정한 중단·정지·특별법 예외를 요건·사실·근거와 정확히 연결한다. 부정·인용·상대방 주장·재반박 및 절 순서 변형도 양방향으로 검사하고 실제 파이프라인 경로를 포함한다. 새/변경 정규식은 수천 회 반복 입력 0.1초 이내 시험을 둔다. 기존 시험·xfail 표시는 수정하지 않는다. 기준은 관련 묶음 310 passed, 2 xfailed와 round7 105 passed, 5 xfailed. 구현 수용은 LEG-2 두 건만 strict XPASS, **XPASS(strict) 외 실패 0**, 고정 81.7/79.2/오탐 0 및 은퇴 세트 하락 없음이며 비공개 게이트·전체 verify_all은 평가 측이 측정한다.
