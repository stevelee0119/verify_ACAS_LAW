# TK-72 통합 CI 시간 여유 보완 (구현 전 설계)

2026-10-10 · 구현 세션 · 시작 `df4a9c0` · 기존 PR #72 보완

**실패.** 사용자 요청에 따라 수용된 TK-72를 성능 보완한다. 평가 통합
`543fc69`의 PostgreSQL/Celery CI에서 기존 32,000건 실제 추출 시험이
1.2964초로 실패했다. SQLite/Docker/점수 게이트 성공과 별도로 실패를
보존한다. 로컬 같은 입력은 0.710832초이므로 기존 구현의 시간 여유가
부족하다. 프로파일에서 법령 정규식 탐색·반복 생성, 문장 경계 탐색,
한국어 본문의 공백 translate가 주요 비용이다.

**구조.** 법령의 필수 `제…조` 위치를 먼저 찾고, 법령명 정규식이 이미
허용하는 길이에서만 선행 이름을 탐색한다. 임의 창을 추가하지 않는다.
이름과 조 사이의 무제한 공백 및 선택적 부칙은 별도로 역추적하며 원래
LAW_RE로 최종 match를 만들어 모든 그룹과 위치·탐색 순서를 보존한다.
문장 경계는 문장부호에서 시작하는 동등한 패턴으로 종료 위치를 찾는다.
네 종류 공백의 같은 길이 치환은 한국어 전체의 Python translate 조회를
피한다. 이전 패턴 구간이 없고 현재 구간이 정렬돼 있으면 봉합 시 기존
목록과 누적 최대 종료 위치를 재사용한다. 필요시 프로파일에 따라 같은
계약을 가진 국소 비용을 더 줄이되 중복 결과를 입력 단계에서 생략하거나
문맥·참조·직접 인용의 계산 범위를 축소하지 않는다.

**계약·상한.** 정규식 공개 심볼, 모든 추출 필드·순서·참조·ID 형식,
문장 경계와 표시/읽기 위치를 유지한다. C개 인용/L자에서 기존
O(L + C log C) 상한을 유지하고 고정 비용을 줄인다. 판정 기준 1초,
32,000건/960KB 이상 입력, 관련 기존 시험·보호 경로는 변경하지 않는다.
두 자리 연도 헌재 승인 예외도 그대로다. 평가 브랜치는 checkout/merge하지 않는다.

**검증·제출.** 시작 SHA와 공개 기준에 대한 전체 필드 합성 비교, 법령명
경계/공백/부칙/괄호/연속 조문·블록별 중복과 문장부호/인용문 양성·대조를
검사한다. 기존 32k·80KB·혼합/학술 시간 시험과 관련 시험, 공개 scorecard,
시험 편집·보호 경로 점검 후 기존 구현 PR에 푸시한다. 최종 SHA의 필수
CI가 성공한 뒤 별도 평가 세션에 #73 통합 재검증을 요청한다. 통합 CI
실패 원본을 재실행 성공이나 최솟값으로 대체하지 않는다.

**8ce425a CI 후 추가 설계.** PostgreSQL PR 실행에서 기존 학술 반복
증가비 시험이 실패했고, push PostgreSQL 실행은 성공했다. 실패 주석을
보존하며 정확한 시간값은 로그 접근 제한으로 아직 확인하지 못했다.
원인 전체를 환경 차이라고 단정하지 않는다. 프로파일과 호출 관계에서
학술 인용만 있어도 사용하지 않는 claim 문장 목록을 만들며, 최종 중복
제거 직전 모든 인용에 읽기 위치 list/tuple을 새로 할당하는 비용을 확인했다.
claim을 쓰는 판례·헌재·법령이 하나도 없을 때만 그 단계를 생략한다.
혼합 입력에서는 모든 인용을 경계 계산에 그대로 사용한다. 최종 중복 키는
변경하지 않고 키에 쓰지 않는 위치·표 셀 속성의 할당만 중복 판정 뒤로
옮긴다. GC 설정·시험 순서·입력·상한을 바꾸지 않고 임시 객체 수를 줄인다.
추가 종료된 PR SQLite에서도 32k 1.0752초 실패를 보존한다. 추출 내부의
임시 인용은 공개 Citation의 같은 dataclass 필드/기본값으로 생성한 slots
형식으로 보관하여 인용마다 인스턴스 dict를 만들지 않는다. 중복 처리 후
반환할 항목만 공개 Citation 객체로 구체화하며 ID와 참조도 기존대로 확정한다.
본문의 기존 중복 키를 모든 추출·참조 해결 뒤에 먼저 계산하여 반환 대상을
정한다. quote/claim의 경계·우선순위에는 모든 후보를 유지하되 반환하지 않을
후보의 파생 속성만 할당하지 않는다. 직접 extract_from_text의 전체 반환은 유지한다.

전체 로그 묶음에서 학술 2k 0.020441/8k 0.733350초를 확인했다. 미확인
상태를 대체하며 실패 자체는 보존한다. 단순 국소 비용 절감에 그치지 않고
중복 법령/학술 항목의 위치·원문·참조 ID는 열 단위 배열로 보관한다. 같은
최종 중복 키/본문 블록의 첫 항목은 전체 객체로 유지한다. 후속 참조와 quote
검색은 모든 위치를 계속 보며, claim은 반환할 항목이 속한 원래 문장 안의
모든 후보를 사용한다. 후보가 없는 다른 문장의 임시 객체를 만들지 않는다.
반복 문서의 임시 객체 수를 줄이되 문장 분할·첫 항목 우선·블록/표 구분·
참조 ID·공개 반환형을 유지한다. GC를 비활성화하거나 강제 수집하지 않는다.
