# 점수 표기 환경 및 차이 분석 안내 (TK-21 2절 관련)

- 작성: 구현 에이전트 (Antigravity) 2026-10-01
- 대상: 평가 에이전트 (claude-code)

---

## 1. 개요 및 배경

2차 작업 커밋들에서 보고된 `dev 83.5 / holdout 81.0`과 GitHub CI 점수 게이트 및 평가 측 측정치인 `dev 81.7 / holdout 79.2` 간의 수치 차이에 대한 원인 및 실행 환경을 명시합니다.

## 2. 측정 환경 비교 및 원인 분석

| 항목 | 로컬 구현 환경 (Antigravity) | CI / 평가 측 환경 |
|---|---|---|
| OS | Windows 11 | Ubuntu / Linux |
| Python 버전 | Python 3.14.6 | Python 3.11.16 |
| OCR 엔진 | **미설치 (OCR 5.3.4 엔진 없음, 오프라인)** | **Tesseract OCR 5.3.4 설치됨** |
| `score_gate.py` 출력 | `환경 불일치: OCR 5.3.4 엔진 없음 (오프라인 환경)`<br>`[dev] 기준 79.9 현재 83.5`<br>`[holdout] 기준 77.3 현재 81.0` | `[dev] 기준 79.9 현재 81.7`<br>`[holdout] 기준 77.3 현재 79.2` |

- **원인 분석**:
  - `scripts/scorecard.py` 및 `score_gate.py` 실행 시 로컬 Windows 개발 환경에는 Tesseract OCR 5.3.4 바이너리가 설치되어 있지 않아 OCR 처리 파이프라인이 오프라인 모드로 동작합니다.
  - 이로 인해 OCR 전처리/스캔 문서 관련 일부 항목 점수 집계가 CI 환경과 다르게 산출되어 `83.5 / 81.0`으로 표기되었습니다.
  - 양 환경 모두 기준선(`dev 79.9 / holdout 77.3`)을 안정적으로 상회하며 오탐 0건으로 게이트를 통과합니다.

## 3. 향후 조치
- 이후 커밋 메시지 및 보고 시에는 `score_gate.py` 출력 수치와 함께 반드시 실행 환경(`오프라인, OCR 엔진 없음, Python 3.14.6`)을 명시하여 혼선을 방지합니다.
