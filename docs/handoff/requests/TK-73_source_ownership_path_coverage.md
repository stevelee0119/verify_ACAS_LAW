# TK-73 source ownership and parser-route coverage redesign

The previous source-aware comparison passed public paragraph controls but did not change the mandatory evaluator outcome. A new public actual-PDF route diagnostic exposes a coverage gap: three independently generated locator/narrative pairs produce duplicate 0 as paragraphs and duplicate 1 as headerless two-column tables. Explicit header-owned title cells repeat without a finding, and genuine distinct inferred-cell subtitles retain A. This is input-route evidence, not a claim that these public examples explain private cases.

`exhibit_rows` currently chooses all recognized table rows instead of line rows whenever any table succeeds. Table identification can be explicit header ownership or content-inferred columns; that distinction is discarded. `_duplicate_mention_view` then treats every `from_lines=False` name as an authoritative title cell and returns before source-aware extraction. The existing generated paragraph PDF/TXT controls therefore cannot certify this route. Do not repair this by deleting table findings or appending narrative rows to the original semantic row set.

Attach comparison-only source ownership to each existing table row: table reference, original row/column position, explicit-header versus inferred-column origin, raw source cell and its local fragments. Preserve the original accepted tables, row counts/order, name/date/author/purpose/reference/section fields and all downstream date/amount/missing-list behavior. Explicit header-owned title cells remain complete authoritative names. Content-inferred text cells are mixed candidates rather than certified title fields: feed their exact source text through the same balanced quote/all-date/delimiter scanner and existing conservative identity corroboration. The original inference does not prove a title boundary; numeric location remains weak, requires positive actual token-edge evidence and exact full-prefix agreement with an independent nonlocator complete-prose candidate in the same party/number/branch. Multiple distinct locator/prose identities, two weak cells, generic/partial prefixes and other groups never certify equivalence. Protected/title date differences and genuine subtitles remain whole. Unknown column/source identity retains baseline comparison.

Cell origins are table-local, not fabricated global reading spans: default reading text omits table/table-line blocks. Record exact original cell string offsets and normalization precision, and only claim block/reading mappings when separately verified. Preserve original cells/fields; no global normalization, footer stripping, lexical location exception lists or finding suppression. For reconstructed PDF tables, retain representation and line-block provenance without treating physical fragment edges as semantic word boundaries. Reuse immutable per-row extraction within `_numbering`, keep group decisions local, and bound new source work by original cell characters/fragments plus branch references; existing parser/inference complexity stays explicitly outside the 0.1-second new-rule timer.

Before product changes, commit a public actual-PDF route diagnostic and unprotected controls: at least three paired paragraph/inferred-table normal cases, explicit-title controls and genuine inferred subtitle positives. Extend generated PDF/TXT/table-source controls to explicit/inferred headers, reconstructed/ruled tables, multiline cells, mixed table+narrative documents, partial prefixes, distinct weak identities, other parties/branches, numeric content, protected dates/quotes, invalid dates, and complete-prose punctuation.
