# TK-67 증거번호 결번 판정 범위 정상화 설계 메모

- 작성: Antigravity (구현 에이전트) 2026-10-09
- 관련 티켓: `docs/handoff/TK-67_exhibit_numbering_gap_section_scope.md`

## 1. 배경 및 문제점
- 현행 `packages/claim_engine/evidence_consistency.py`의 `_numbering` 함수는 서면 내 추출된 모든 행(`in_section` 목록 구역 행과 본문 언급 행 모두)을 합산하여 `range(1, max(numbers) + 1)`로 1번부터 무조건 결번을 판정함.
- 이로 인해 발생하는 부작용:
  1. 서면의 입증방법 목록이 2번부터 시작하는 정상 서면(이전 기일 등에 1호를 이미 제출한 경우 등)에서 '제1호증 결번' 대조군 오탐 발생 (은퇴 `sealed_20261009` SD-01).
  2. 본문에서 별도로 큰 호증 번호를 단순 인용·언급했을 때 목록 끝 번호부터 해당 번호까지 대량의 결번 오탐 발생 (은퇴 `sealed_20261008b` SD-02). 본문 언급 번호의 목록 누락은 `EVIDENCE_LIST_MISMATCH`가 정규 담당함.

## 2. 설계 변경 내용 (기본형)
1. **목록 구역이 존재하는 당사자 행**:
   - 결번 판정 대상 번호를 목록 구역 행(`in_section` 참인 행)의 번호 집합(`sec_nums`)으로만 한정한다. 본문 언급 행 번호는 결번 계산에서 제외한다.
   - 결번 산출 범위를 목록 구역의 최소 번호부터 최대 번호까지(`range(min(sec_nums), max(sec_nums) + 1)`)로 한정한다. 즉, 첫 번호 앞의 번호는 결번으로 보지 않는다.
2. **목록 구역이 없는 서면 (본문 언급 행만 존재하는 경우)**:
   - 기존 동작을 그대로 유지한다 (`range(1, max(numbers) + 1)`로 1번부터 결번 산출).
   - 이유: 은퇴 세트 SD-07 등 본문 기반 결번 탐지 경로의 채점 회귀 방지.
3. **영향 범위 제한**:
   - 가지번호 결번(`missing_branches`) 및 호증 번호 중복(`EVIDENCE_NUMBER_DUPLICATE`) 로직은 일절 변경하지 않는다.

## 3. 검증 계획
1. **합성 시험 (7건 이상)**:
   - 양성 유지: 목록 구역 내부의 중간 결번(1·2·4 → 3 결번), 다양한 당사자 부호(갑·을·증 등) 3건 이상.
   - 대조군 오탐 해소: 목록 구역이 2번 이상부터 시작하는 서면, 본문이 큰 번호를 언급하고 목록 구역은 연속인 서면, 가지번호만 있는 서면 3건 이상.
   - 목록 구역 미존재 서면의 기존 동작 유지 1건 이상.
2. **성적표 및 회귀 점검**:
   - 고정 dev(81.7), holdout(79.2), 오탐 0 유지.
   - 은퇴 a(19.0), 은퇴 b(29.6) 유지 및 은퇴 `sealed_20261009` 대조군 오탐 해소(34.2/1 → 36.2/0).
