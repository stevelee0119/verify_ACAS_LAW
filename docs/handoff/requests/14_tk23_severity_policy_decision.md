## 1. 배경 및 현황

### (1) TK-23 A 소관 완료 현황
- 공식 법령 목록 부재 시 내부 규정·행정규칙·지침 형태의 인용에 대해 CRITICAL 부존재 법령 판정을 남발하던 결함을 해소했습니다.
- 사용자 참고자료(Drive)에 규범명이 존재하는 경우 "참고자료에서 확인(공식 법령 아님)"으로 식별하여 `STATUTE_NONEXISTENT` CRITICAL을 발행하지 않고 원문 대조로 연계합니다.
- 참고자료에 없더라도 내부 규정·행정규칙·지침 형태이면 심각도 `LOW` (HIGH 미만)로 보고하며, 일반 법령(법·법률·시행령 등)의 경우에만 기존 `CRITICAL`을 유지합니다.
- 단위 시험 9건(양성 6건, 대조군 3건) 및 5대 검증 게이트를 전건 통과했습니다.

### (2) TK-23 B 현안 (사용자 결정 대기)
현재 `legal_engine/source_review.py::_article_absent`의 판정 정책:
- 기준일 시행 버전의 전체 조문(예: 국가배상법 19개 조문)을 전수 대조하여 해당 조문(예: 제2조의3)이 없는 경우:
  - 증거 등급: `A` (조회한 공식 버전의 전체 조문 목록에 해당 조문 없음)
  - 심각도: 현재 **`MEDIUM`** 고정
- 반면 공식 DB 조회 범위 내 미발견인 판례(대법원 2022다29841 등)는:
  - 증거 등급: `B` (조회 범위 내 미발견, 부존재 확정 아님)
  - 심각도: 현재 **`CRITICAL`**

이로 인해 "가장 확실한 증거(A등급 전체 조문 대조)의 심각도가 더 약한 증거(B등급 판례 미발견)보다 낮게 보고되는 역전 현상"이 존재합니다. 정답지에서는 이를 "Critical Error"로 분류하고 있으며, 평가 명세(`case9_state_compensation_online.json` EX-2s)는 HIGH 이상을 기대합니다.

## 2. 사용자 결정 요청 사항

기준일 시행 버전의 전체 조문 대조에서 조문이 없는 경우(`_article_absent`), 심각도를 어떻게 책정할지 결정해 주시기 바랍니다:

### 옵션 1 (평가 측 제안안 - 권장)
- **심각도**: `HIGH`로 상향.
- **근거**: 기준일 시행 버전의 전체 조문 전수 대조(증거 A등급)이므로 객관적 근거가 확실함. 단, 다른 시행 버전이나 부칙에 존재했을 가능성을 고려하여 "허위 인용 단정 아님" 문구는 유지.

### 옵션 2 (정답지 완전 일치안)
- **심각도**: `CRITICAL`로 상향.
- **근거**: 정답지의 "Critical Error" 분류와 직접 일치시킴.

### 옵션 3 (현행 유지안)
- **심각도**: `MEDIUM` 유지.
- **근거**: 조문 오기나 부칙 조항일 가능성을 열어두어 보수적으로 경고만 제공.
