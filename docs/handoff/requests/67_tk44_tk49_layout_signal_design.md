# TK-44·TK-49 1단계: 문단 국소 레이아웃 신호 설계

기준: Steve `0bf4ccc`, 평가 측 PR #61 티켓 「재개(2026-10-10)」 및 사용자 통합 지시 (11). **이번 PR은 설계 문서만**이며 구현·보호 시험 편집은 하지 않는다.

1. **현재 경로와 수집.** `PdfParser.parse`는 pdfplumber의 `page.chars`를 이미 읽고 `_group_chars_to_lines`로 묶는다. `.strip()` 전의 양끝 공백 글리프, 글자의 x0/x1·크기·폰트·회전, 줄 끝 여백과 글자/공백 간격의 요약을 같은 순회에서 `Block.attributes`에 남긴다. 신규 PDF 라이브러리나 전체 재추출은 쓰지 않는다. 숨김·표·다단·OCR·PUA 복원/불일치 처리는 보존하고 신호를 확인하지 못한 대체 파서·OCR에는 UNKNOWN을 준다.
2. **문단 국소 판정.** `reconstruct_page_blocks`의 확정된 문단 그룹 안에서만 대표 글자 폭·공백 폭·왼쪽 정렬·비마지막 줄 끝 분포를 1회 계산한다. 쪽의 다른 문단이나 `0.75 * page_width`를 문단 오른쪽 끝의 증거로 쓰지 않는다. 단위는 글자 폭/폰트 크기로 정규화한다. 반복 줄 끝과 정상 글자 간격이 함께 관측되면 글자 줄바꿈 후보, 다음 어절을 통째로 넘긴 여백 패턴이면 어절 줄바꿈 후보다. 다만 좌표상 동일한 결과는 양쪽 줄바꿈 방식에서 모두 나올 수 있으므로 **여백·꽉 찬 줄 하나만으로 확인됨/아님을 확정하지 않는다**. 공백 글리프처럼 경계가 직접 보존된 증거와 일관된 문단 내 관측이 없으면 UNKNOWN이다. 글자/어절 줄바꿈 모드와 해당 경계의 공백 증거는 별개로 기록한다.
3. **전달 계약.** `join_lines`에 키워드 전용 `boundary_signal=UNKNOWN`을 추가한다. 값은 `JOIN_CONFIRMED / SPACE_CONFIRMED / UNKNOWN`의 세 상태이며 문단의 `char_wrap_state`(확인됨/아님/모름), 국소 right_edge·end_gap_em·char_gap_em·space_gap_em·직접 공백 유무와 함께 기록한다. SPACE_CONFIRMED는 공백을 보존하고 JOIN_CONFIRMED는 연결한다. 문단의 글자 줄바꿈 모드만으로 모든 경계를 JOIN으로 만들지 않는다. 원본 글리프 식별 범위와 판단 사유 코드를 보존해 재현할 수 있게 한다.
4. **모름과 호환성.** UNKNOWN은 현재 `join_lines(prev, nxt, prev_full, char_wrap_context)` 동작으로 위임한다. 기존 호출·원장 기대값·고정 사본을 그대로 지킨다. 신호가 없는 TXT/DOCX 호출은 UNKNOWN이다. 신호 부재를 “어절 경계 아님”으로 바꾸거나 새 기본값으로 어느 한쪽을 통과시키지 않는다. 새 신호는 확인된 경계의 기존 휴리스틱보다 먼저 적용하되 괄호·닫힘 기호의 보존과 출처 오프셋을 함께 검사한다.
5. **괄호 뒤 판단.** 열림/닫힘 기호 자체의 접속은 문자열 구조로 가를 수 있다. 그러나 열림 괄호 뒤 1~2음절이 독립 어절인지 긴 어절의 일부인지는 문자열 구조만으로 일반적으로 구별할 수 없다. R6-03 3건·R7-05 2건도 평가 측에 SPACE_CONFIRMED 등 경계 신호를 전달하는 시험으로 수정 요청한다. 원장의 괄호 뒤 어절 분절은 UNKNOWN의 기존 동작으로 보존한다. 관형어·의존명사·예외 낱말 목록은 추가하지 않는다.
6. **시험·선행조건.** 평가 측이 R7-05 prev_full 3건 및 필요한 괄호 뒤 시험의 신호 전달을 승인·수정하고, TK-56이 수용된 뒤에만 최신 Steve를 받아 구현한다. 확인된 붙임/띄움/모름 각각 합성 3건 이상, 같은 문자열에 다른 레이아웃, 실제 합성 PDF 글자 좌표→parse_document 경로, 다른 문단/쪽 배치·폭·폰트 변화, 모름의 원장 사본 2종 불변을 시험한다. 문단 신호 계산은 글자 수에 선형, 경계 판정은 상수 작업으로 설계하고 수천 회 0.1초 시간 시험을 둔다. 보호 시험 수정·새 비공개 세트·Google Docs PDF/DOCX·고정 점수 수용은 평가 측에 맡긴다. 신호를 좌표로 확인할 수 없는 경우는 미해결로 보고한다.
