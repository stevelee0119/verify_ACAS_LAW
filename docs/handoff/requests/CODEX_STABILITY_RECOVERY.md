## 원장 복구

최신 기준 커밋에는 삭제됐던 6개 함수가 다시 존재한다. `4da3910`과 AST를 비교하면 TK-35·36/37·38·39·40은 원본과 같고, TK-41만 다르다. TK-41의 `(대` + `법원 ...)` 기대값이 `(대 법원 ...)`으로 약화됐던 변경을 원래 `(대법원 ...)`으로 복구했다. 다른 assertion이나 표시를 바꾸지 않았다.

TK-41의 알려진 문단 결합 실패는 이번 법리 수정으로 해결되는 문제가 아니다. 7D 지시서의 이 함수 strict xfail 승인과 실제 `check_test_edits.py`의 신규 표시 차단이 충돌하므로 구현 측에서 표시를 추가하여 실패를 숨기지 않는다. 평가 측은 보존된 `test_pinned_ledger_4da3910_additions.py`와 같은 계약으로 미해결 상태를 관리해야 한다. 이 원장 실패가 남으면 전체 게이트 완료라고 보고하지 않는다.

## 법리 수정 수용 기준

- 변경 전후 같은 합성 입력으로 비교하고 새 규칙마다 양성·대조군을 함께 검증한다.
- 요건 절의 부정과 결론 절의 책임 부정을 구분한다. 법률별 요건은 기존 설정을 사용하며 사건 문구를 예외로 추가하지 않는다.
- 부재가 필요한 요건은 극성 메타데이터로 표현한다. 이는 서면이 요건 충족을 주장하는지의 문장 검토이며, 법률요건 전부의 실제 충족이나 판결 결과를 확정하지 않는다.
- 인용·상대방 주장·재반박 처리, 기존 정상 항변, 실제 TXT 파이프라인 경로를 보존한다.
- 고정 개발 81.7 / holdout 79.2, 오탐 0 기준을 낮추지 않는다. 합성 시험 개선은 새로운 봉인 서면의 일반화 성능으로 표시하지 않는다.
