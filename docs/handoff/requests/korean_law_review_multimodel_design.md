# 다중 모델·커넥터 범위 결정 (2026-10-10)

**확정 범위:** 사용자는 이번 PR에서 선별한 Claude for Legal 스킬 지침만 기존 Claude 서버 API에 적용하고 실제 MCP는 한국법 자료·권한 확인 뒤 별도로 연결하는 권장안을 선택했다. 기존 `claude-opus-5-5`, `gemini-3.8-flash`, `gpt-6-luna` 모델 설정은 유지한다. OpenAI/Gemini의 기존 작업·fallback·주장 의견 호출은 그대로 사용한다. 처음 설계한 `consult_all` 공통 적용은 철회했으며 현재 경로는 `review_document → LLMRouter.run`이다.

**OpenAI·Gemini 판단:** 근거 확인·반론 검토 방법론은 이들에도 유용할 수 있지만, 이번 PR에서 추가 스킬/법률 전용 서비스/새 검색을 도입할 필요성이나 한국법 품질 우위를 입증하지 못했다. 사용자는 법률 특화 서비스의 구독 비용·접근 제한을 우려해 Claude만 추가 활용하도록 범위를 정했다. 특정 공급자의 모든 법률 기능이 기업 구독에 한정된다고 확인한 것은 아니며, 실제 상품/계정 권한은 별도 확인 대상이다. 검증되지 않은 구독 권한을 전제로 새 API를 구현하지 않는다. 기존 텍스트/JSON API와 보호 경로를 유지하는 것이 이번 수용 기준 및 사용자 선택에 맞다.

**Claude for Legal·Claude Code 구분:** 공개 Claude for Legal은 검토 스킬·명령·커넥터를 묶은 플러그인이며 별도 서버 법률 모델이 아니다. 이번 구현은 필요한 공개 지침을 선별·재작성해 실제 API system에 전달한다. Claude Code 설치/플러그인 설정이나 앱 구독 권한이 서버 API/MCP에 자동 적용된다고 가정하지 않는다. Claude Code 실행기·자동 에이전트·플러그인 전체는 설치하거나 실행하지 않는다. 현재 계정이 특정 법률 커넥터를 쓸 수 있다고 단정하지 않는다.

**MCP 후속 조건:** 첫 단계 추가 없음. 기존 한국 공식 DB와 원문 대조를 최우선으로 사용한다. 별도 평가에서 한국법 원문/연혁 접근 부족이 확인되면 실제 커넥터 이름·한국법 수록 범위·시행본·공식 원문 대조·자료 라이선스·앱/API/MCP 각각의 서버 접근 권한·개인정보 전송·비용·지연·취소/timeout 경계를 확인한 뒤 읽기 전용 연결을 별도 설계한다. 후보 자료 범위는 국가법령정보센터의 법령 연혁·판례/헌재 결정 및 대법원 공식 판결이다. 해외 법률 자료나 연결된 업무 앱은 한국법 공식 확인을 대신하지 않는다.

**평가:** 실제 동일 조건 OFF/ON에서 Claude의 법률 판단·근거·반론/차이·무근거 주장·오탐/누락/유보·비용/지연을 검토한다. OpenAI/Gemini는 기존 fallback 입력 및 보호 계약의 회귀 대조군으로 확인한다. 실제 모델 응답 품질과 비용/지연이 측정되기 전에는 기능 개선이 수용되었다고 주장하지 않는다.
