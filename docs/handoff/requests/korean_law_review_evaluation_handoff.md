# 한국법 검토 프로필 평가 인계 요청

구현 세션의 제출이며 수용 판정이 아니다. 사용자 요청(2026-10-10)에 따라 법률 판단 개선·비용 증가·시간 지연을 확인하기 전 운영 반영하지 않는다. 구현은 새 공개 합성 시험만 사용했다. 평가 자산·기준선·비공개 입력·기존 시험의 열람/수정/실행을 요청하지 않는다. 별도 평가 세션이 평가 도구와 자료를 관리하고 수용 SHA만 통합한다.

## 실행 구분

1. **지침 효과:** 동일 모델 ID·마스킹된 입력·공식 근거·기준일·스키마·temperature·상한에서 `build_opinion_request`의 `korean_profile`만 바꾼다. 두 팔 모두 같은 보강 원문/context를 제공한다. 호출은 기존 LLMRouter와 각 정책/예산/시간 상한을 사용한다.
2. **전체 운영 효과:** 실제 끔/켬 경로를 같은 원본 입력·공식 조회 결과로 비교한다. 켬의 원문/context 입력 보강과 행 ID 보존도 효과에 포함되므로 이를 순수 지침 효과로 부르지 않는다.
3. Anthropic/OpenAI/Gemini별 비교를 따로 기록한다. 운영의 다중 모델 의견도 별도 기록하되 합의 자체를 공식 확인이나 품질 향상으로 세지 않는다. 실제 공급자 모델 변경·검색 결과 차이·누락·재시도/격리를 기록해 비교 조건을 확인한다.

## 측정·판정 요청

| 항목 | 평가 측이 확인할 증거 |
|---|---|
| 법률 판단 정확성 | 한국법 공식 원문·시행본과 문서 사실을 기준으로 변호사가 판단한 정답/허용 판단 범위. 출처 없는 단정은 감점 |
| 근거 충실도 | 주장–요건–사실–원문 연결, 정확한 원문 인용, 출처 위치, 기준일 적용. 원문이 잘렸을 때 유보했는지 |
| 반론·적용 차이 | 가장 강한 반론·사안 차이·예외 요건을 근거로 설명했는지. 새 사실을 만들어 반론을 채우지 않았는지 |
| 무근거 주장 | 입력에 없는 사건번호·조문·인용문/사실의 생성 건수. 공식 확인 상태의 부당한 상승 여부 |
| 오탐·누락·유보 | 확인 가능한 주장/부족한 주장/충돌 자료를 구분하는 정확성. 유보가 필요한 곳과 불필요한 과도한 유보를 함께 기록 |
| 비용 | 모델별 input/output tokens·cost_usd·cost_status와 전체 실행 비용. 공급자 청구/usage와 대조; ESTIMATED를 실측으로 쓰지 않음 |
| 지연·안정성 | 동일 조건의 요청 지연·전체 실행 벽시계 시간 분포, timeout/잘림/격리·실패·재시도·실제 호출 건수 |

평가 시작 전에 허용 가능한 품질 회귀·무근거 주장·비용 증가·지연 상한과 표본/반복 계획을 평가 측/사용자가 정한다. 현재 결과를 보고 기준을 낮추지 않는다. 결과는 가능하면 지침을 가린 짝 비교로 검토하고 모델 응답의 변동을 반영한다. 자기평가·문장 길이 증가는 개선 지표가 아니다. 고정 오프라인 점수 외에 새 입력의 온라인 한국법 검토를 확인하고 개선/회귀와 비용·지연의 절충을 사용자에게 제시한다.

## 현재 구현 결과·제약

- 새 공개 합성 계약/보호 시험 47건 통과. 실제 네트워크 법률 모델 호출·변호사 품질 판정·실제 비용/지연 측정은 수행하지 않았다. 기존 시험은 별도 CI/평가 측 소관이다.
- 기본 꺼짐. 적용은 기존 법률 주장 참고 의견 경로에 한정된다. 전체 법률 검토·확인 판정·RAG·소송 절차 변경이 아니다.
- 원문은 마스킹/지시문 제거 후 최대 6,000자 앞부분이다. 뒷부분의 요건/예외 누락 위험이 있다. 기준일 미지정 또는 원문 부족 때 판단 유보가 실제로 지켜지는지 평가해야 한다.
- 프롬프트는 무근거 인용을 금지하지만 새 인용 검증기를 추가하지 않았다. 원문 근거성·환각 감소는 실제 응답으로 확인할 대상이다.
- 기존 배치/재시도 정책은 같지만 지침·원문 입력 증가로 토큰·지연·실제 재시도 횟수가 증가할 수 있다. 실측 없이 증가율을 주장하지 않는다.
- 설정 재로드 뒤 새 실행에 켬/끔을 적용한다. 기존 worker의 스냅샷 드리프트 차단은 유지한다. 진행 중 호출의 프롬프트를 바꾸지는 않는다.
- 새 MCP/플러그인 설치, Astra 도입, 모델 교체, 버전 상향, 기준선 변경은 없다. TK-72·74 PR/브랜치와 분리했다.

최종 SHA·시험 명령/결과·diff stat은 PR에 보고한다. CI 종료 및 별도 평가 세션의 검토·수용 전 병합/배포하지 않는다. **검토 요청.**
