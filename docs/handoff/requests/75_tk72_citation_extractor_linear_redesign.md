## 1. 기존 접근의 실패 원인 분석 (Why Previous Approaches Failed)

1. **학술자료 상한 설정의 의미/위치 왜곡**:
   - 1차: 저자 반복 `{0,9}` 상한 → 저자 11명·12명 인용에서 앞부분 누락 (의미 회귀).
   - 2차: 제목 앞 600자 유한 창 상한 → 저자 250명 등 대규모 저자 목록에서 앞부분 51명 절단 (원문/위치/저자 회귀).
   - **근본 원인**: 저자 수나 글자 수와 같은 인위적 상한으로 백트래킹을 제어하려 한 접근 자체가 정상 경계를 훼손함.

2. **`SpanTracker`의 패턴 간 투 포인터 머지 지연(flush) 병목**:
   - 새 구간을 `pending`에 넣고 다음 인용의 `overlaps()` 호출 시마다 전체 `_flush()`를 수행.
   - 판례와 법령 등 서로 다른 패턴의 인용이 번갈아 나오는 텍스트에서 인용마다 O(N) 병합이 발생하여 O(N²)로 퇴화 (8,000문장에서 6.46초 시간 회귀).

3. **키워드 선행 필터(Fast Pre-check)의 과도한 차단**:
   - `FULL_CASE_RE` 앞머리에 `판결|결정|선고` 등을 필수로 요구하여, 선고/종결어가 없는 유효한 판례(두 자리 연도 헌재, 약식 판례 표기 등)가 추출 0건으로 누락됨.

4. **해석례 앞 공백 분기 불일치로 인한 중복**:
   - `INTERPRETATION_RE`의 앞머리 기관명 분기를 수정하는 과정에서 앞 공백(`\s*`) 소비 범위가 달라져, `INTERPRETATION_FULL_RE`와 맞닿은 구간이 독립된 2번째 인용으로 중복 추출됨 (1건 → 2건).

## 2. 신규 설계: 정상 경계 보존 및 전체 경로 복잡도 보장

### A. 학술자료: 2단계 선형 파서 (Two-Phase Linear Parser)
정규식 중첩 반복에 의한 백트래킹을 배제하고, 결정적 2단계 파싱으로 정상 경계를 100% 보존한다:
1. **1단계 (제목 앵커 및 출판정보 매칭)**:
   - 제목 낫표/따옴표(`[「『"“]...[」』"”]`)와 뒤따르는 출판정보(`,\s*학술지...권/호...연도`)를 정규식으로 먼저 탐색.
   - 제목 내부는 유한 문자(`[^」』"”]{5,120}`)로 한정되어 백트래킹이 원천 발생하지 않음.
2. **2단계 (제목 앞머리 역방향 선형 토큰 스캔)**:
   - 제목 시작 위치의 앞 문자열에서 쉼표(`,`) 직전까지를 대상으로, 문장 경계(직전 개행 또는 마침표)까지 뒤에서 앞으로(오른쪽→왼쪽) 유효 저자 이름 토큰(`[가-힣][가-힣○△□*]{1,3}`)을 선형 탐색.
   - **경계 보존**: 저자가 1명이든, 250명이든, 1,000명이든 임의의 길이에 대해 전원 보존 (글자 수·저자 수 상한 0).
   - **백트래킹 방지**: 앞에 `·`가 80,000개 있더라도 저자 이름이 없는 위치에서 즉시 스캔이 중단(break)되므로 O(1) 시간에 완료.

### B. `SpanTracker`: 패턴 단위(K=상수) 투 포인터 병합 (O(N log N) 보장)
1. **정규식 패턴 단위 실행**: 인용 추출기는 약 10개 정규식 패턴(K≈10)을 순차 실행함.
2. **패턴 내 O(1) 추가**: 각 패턴의 `re.finditer`는 텍스트를 전진 스캔하므로 단일 패턴 내의 구간들은 항상 정렬 상태임. 따라서 패턴 실행 중에는 임시 리스트에 O(1) `append`.
3. **패턴 종료 시 1회 머지**: 패턴 1개가 끝날 때 기존 누적 정렬 리스트와 단 1회 O(N) 투 포인터 병합 수행.
4. **복잡도**: 전체 머지 횟수는 총 K회(약 10회)로 고정되므로, 전체 병합 비용은 O(K · N) = **O(N) 선형 시간**임.
5. **겹침 검사 (`overlaps`)**: 이미 정렬된 누적 리스트에서 `bisect` 이진 탐색으로 **O(log N)** 보장.

### C. 판례 인용의 온전한 복원 (기존 정규식 선택성 100% 유지)
- `FULL_CASE_RE`, `CONST_RE`, `BARE_CASE_RE`에 대해 종결어 필수 선행 필터를 완전히 제거.
- 종결어가 없는 판례("대법원 2024. 1. 15. 2023도12345", "(헌재 1990. 9. 10. 89헌마82)" 등)도 원본과 완전히 동일하게 100% 정상 추출.

### D. 해석례 중복 제거 및 공백 백트래킹 방지
- "법령해석" / "유권해석" 키워드가 문서에 존재하는 경우에만 `INTERPRETATION_RE`를 실행하여 80KB 공백 반복 백트래킹을 원천 스킵.
- 키워드 존재 시에는 03fdcdb 원본 정규식 형태를 유지하여 앞 공백 경계 어긋남에 의한 1건→2건 중복 추출을 원천 해결 (기준 대비 차이 0).
