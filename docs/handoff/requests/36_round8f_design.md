# 8F 설계 메모 — 성명 8C 수렴, 연락처·주민번호 표기 정규화

## 설계

- 성명 문맥은 `privacy.py`를 `86bd035` 판으로 되돌리고, 구조화 키 라벨의 출처를 `detector.STRUCTURED_PERSON_KEY_LABELS` 하나로 맞춘다. English label phrase는 긴 구부터 정렬하며, 감지된 English label은 합성 문맥에서 detector가 인식하는 `이름`으로 바꾼다. detector의 평문 정규식은 그대로 둔다.
- 연락처·주민번호는 원문과 별도인 숫자 탐지 뷰를 만든다. 각 문자에 NFKC를 적용하고, 숫자 사이의 공백·줄바꿈·구분 기호를 정규화해 기존 유형·길이 패턴을 적용한다. 정규화 문자마다 원문 위치를 보관해 탐지 span을 원문 구간으로 되돌린다. 다른 PII 탐지기는 원문에서 현재처럼 실행한다.
- 오탐 억제는 라벨·법률 식별자 가드를 정규화 뷰에도 적용하고 PHONE/RRN 패턴에만 정규화를 한정하는 것으로 한다. 다른 숫자 탐지와 PERSON 판정은 바꾸지 않는다.

## 시험

새 합성 연락처·주민번호 변형을 원문 span 및 실제 `LLMRouter.run`의 user, system, 구조화 값에서 검사한다. 사건번호·날짜·금액·사업자번호·법인등록번호·법령 번호 대조는 전송 여부와 PHONE/RRN 오탐 부재를 확인한다.
