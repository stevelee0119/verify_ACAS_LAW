# 작업별 모델 배치와 비용 집계 개선

2026-10-17 사용자 요청: 가격 대비 법률문서 검토 성능 개선안을 적용한다.
기준 main b68cfee. 기존 판정·증거등급·개인정보 검사·공식 출처 우선순위·예산 상한은 유지한다.

## 구현

- 로컬 추출·공식 DB 대조는 유지한다. 일반 법리/RAG는 Sonnet, 독립 법리 검토는 Sol,
  작성 정황의 보조 분석은 Luna를 우선 사용한다. 자료의 문구나 모델 자신감만으로 법률 검토를 생략하지 않는다.
- 기본 auto에서는 법률 검토에 서로 다른 공급자 두 곳을 사용하고, 의견 충돌·실패에는
  제3 공급자/Opus의 추가 참고 검토를 수행한다. all/off 명시 설정은 보존한다.
  Opus 추가 의견이 기존 충돌을 다수결로 해소하거나 판정을 승격하지 않는다.
- 작성 정황 보조 분석의 이상 없음 결과는 결정적 표본으로 추가 검사한다.
  문서 단위/주장 단위 RAG는 분모·상한·원문 검증을 보존하고 공급자 장애 대체를 보완한다.
- 동일 실행 내 동일 요청은 검사와 권한/예산 확인을 거친 뒤 결과를 재사용한다.
  실행 경계·입력·기준일·모델·정책이 다르면 재사용하지 않는다. 외부 저장소는 만들지 않는다.
- 모델별 단가, 사고/캐시 토큰, 캐시 쓰기·읽기 비용을 구분한다. 알 수 없는 사용량은
  추정/미확정으로 보존하고 오류를 무료라고 단정하지 않는다. 기존 예산액을 확대하지 않는다.
- 운영 지침을 환경변수 예시와 함께 제공한다. Batch API는 실시간 경로에 넣지 않고
  비실시간 작업의 후속 선택사항으로 문서화한다.

## 검증과 한계

신규 모의 공급자 시험으로 모델 분리·원본 설정 불변·독립 검토·충돌 시 유보·정책/예산 차단·
장애 대체·재사용 경계·사용량 정산을 검증한다. 기존 라우터·원장·RAG·한국법 프로필·관련 개인정보
회귀시험을 수정 없이 실행한다. 고정/봉인 정답과 보호 경로는 변경하지 않는다.
실제 한국어 법률문서 품질·청구액 개선은 배포 전 독립 평가 대상이며 모의 시험으로 입증하지 않는다.
별도 작업 브랜치/PR로 제출하고 CI·독립 검토 뒤 기존 릴리스 절차를 따른다.
