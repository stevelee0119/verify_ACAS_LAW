**재현한 실패와 원인.** 공개 scorecard는 79.9/77.3/0, 관련 시험은
49 통과/4 실패(삭제된 `ACADEMIC_RE` import)다. 합성 비교에서 같은 패턴의
미봉합 구간을 overlaps가 보지 못해 이중 공백 조문 내부를 다른 조문의 참조로
추가한다. 쉼표 저자를 분리하고 문장·줄바꿈에서 저자 체인을 잘라 필드 계약을
바꾼다. 제목마다 전체 prefix 복사/rfind, 참조 목록 insert, 긴 문장별 반복
prefix/claim 복사와 quote×citation 순회, 행정규칙의 문장 재탐색이 남아 있다.
키워드 사전 차단은 INTERPRETATION_RE의 공백 재시도를 해결하지 않는다.

**바꿀 구조.** 패턴별 구간은 미봉합 구간까지 즉시 질의하며 원본의 두 끝점
겹침 조건을 유지한다. 정렬 구간과 prefix 최대 종료 위치를 색인하고 패턴
전환에만 병합한다. 법령 구간을 먼저 봉합한 뒤 참조와 기존 조문을 종료 위치
순으로 병합 순회한다. 학술은 기존 제목/출판정보를 앵커로 삼고 원 문자열의
위치에서 저자 체인을 역순으로 읽는다. 전체 prefix 복사·임의 문장 경계·저자
수/길이 창 상한을 쓰지 않는다. 호환 `ACADEMIC_RE.finditer`는 원래 이름/번호
그룹과 span을 제공하며 제품 경로도 이 매처를 공유한다. authors는 원본처럼
가운뎃점만 분리한다. 해석례는 필수 낱말 위치에서 앞 공백/기관명을 복원한다.
문장·괄호·쉼표·인용 위치를 문장당 한 번 색인하며 출력 400자 claim은 공백
축약 위치를 이용해 얻는다. 행정규칙 문맥은 문장 색인으로 재사용하고 법령
약칭은 정렬 이름의 접두 범위로 질의한다. 목 파서의 기존 100자 창은 그대로
호출하되 전체 suffix 복사를 피한다. 표 칸은 조각을 모아 한 번 결합한다.

**보존과 상한.** 추출 순서, raw_text/span, 그룹·authors·attributes·참조 관계,
전체 입력 크기와 시간 기준을 보존한다. 고정 패턴 수에서 길이 L, 인용 C,
인용문 Q에 대한 계산 비용은 O(L + (C+Q) log(C+Q) + 출력 크기), 메모리는
O(L+C+Q)다. 긴 문장·학술 반복도 포함한다. 두 자리 연도 헌재는 이전 회복
출력을 유지하라는 지시와 기준 CASE/판결 출력이 충돌하여 사용자에게 확인을
요청했다. 그 항목을 제외하고는 의미 변경을 도입하지 않는다.
