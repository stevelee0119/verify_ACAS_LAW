# TK75 배포 후 온라인 OFF/ON 결과 대조 (현행 실행 계획)

사용자 결정: 법률 품질 검토를 온라인 실행결과 점검에서 적용/미적용 결과 상호 대조로 수행한다. 사전 API A/B·통계 통과는 배포 선행조건이 아니다. 기술 포함은 기본 OFF; 실제 개선·정식 활성화는 별도 판단한다. 이 문서는 지금 설정 전환/온라인 호출을 실행했다는 보고가 아니다.

1. **배포 확인 후 준비:** health commit이 실제 main 병합 SHA와 같고 DB ok여야 한다. API와 worker 모두 같은 배포/설정인지 확인한다. Render 내부 키를 그대로 사용하고 키/설정 전체 덤프를 PR·대화·작업 파일로 옮기지 않는다. 월 잔액·실행 예산·쿼터 조회 권한을 확인한다. 총 지출은 min(USD40, 실제 잔액, 기존 실행 한도), 예약/재시도/fallback 비용도 포함한다. 조회 못 하면 유료 실행을 시작하지 않고 그 제한을 보고한다.
2. **비교 조건 고정:** 사용자와 평가 측이 대표 입력 몇 건 및 채점 관점(정확성·근거·반론/사안 차이·누락/오탐·유보)을 실행 전에 고정한다. 같은 문서 바이트 hash·릴리스 SHA·Claude 모델 ID/파라미터·참고자료 snapshot·명시 기준일을 짝지어 기록한다. 참고자료/공식 자료가 변경되면 동일조건 비교에서 분리한다. 30개 기준 후보는 변호사 검증을 거친 항목만 활용하며 검증 전 gold로 가정하지 않는다.
3. **프로그램 전체 OFF/ON 실행:** 기존 업로드→검토/라우터→마스킹·입출력 검사→보고서 경로로 각각 새 실행을 만든다. `LV_KOREAN_LAW_REVIEW_PROFILE=0/1`을 API와 worker에 일치시켜 재로드하고 snapshot/prompt_version/provider로 실제 조건을 확인한다. 진행 중 작업을 배수한 뒤 전환하며 다른 사용자 작업에 영향을 주면 분리 테스트 서비스 또는 승인된 점검 시간에만 수행한다. ON은+kr2 캐시 분리; 기존 완성 보고서 재사용을 새 실행으로 세지 않는다. 순서는 기록하고 같은 모델 호출을 무조건 두 배로 자동화하지 않는다.
4. **실제 경로 확인:** 허용 Claude PRIMARY_REASONER의 drive_rag_advisory/claim_rag_advisory에만 적용됐는지 확인한다. OFF/ON에서 ON 관할/기준일 context 차이도 기록해 전체 기능 효과로 보고한다. 다른 모델/fallback은 기존 요청을 유지한다. Claude 호출 실패·retry·timeout·잘림·fallback도 전체 실행 기록에 포함하며 fallback 결과를 Claude 품질 개선으로 집계하지 않는다. 비슷한 문장/길이·모델 자기평가는 법률 개선 근거가 아니다.
5. **법률 채점:** 독립 한국 변호사 **1명**에게 X/Y 무작위 코드로 OFF/ON을 가린 보고서와 동일 근거 자료를 준다. 쟁점·요건·사실/근거 연결·반론/차이·누락·오탐·부적절한 단정/과도한 유보·중대한 오류/허위 사건번호/조문/인용을 같은 기준으로 비교한다. 미결은 그대로 남긴다. 복수 채점자 간 불일치·제3판정은 없다. 채점 고정 후 대응표를 공개해 대조한다.
6. **비용/안정성 검토:** 입력/출력 토큰, actual/estimated 비용 구분, usage/cost_status, 실행 지연, 실패/retry/fallback 수·커버리지를 조건별로 집계한다. 같은 유효 쌍으로 평균 비용과 p95 변화를 가능한 경우 계산한다. +20%는 참고 목표이고 소표본 p95는 참고값이다. 예산 도달 시 추가 반복 중단, 누락/유보·실패를 숨기지 않는다.
7. **종료/권고:** 확인된 중대한 법률 오류·허위 인용·보호 회귀면 ON 점검 중단·API/worker OFF 복귀를 확인하고 티켓으로 넘긴다. 한 보고서로 계속 활용/보완 후 재검토/기존 지침 복귀를 권고한다. 개선 불명확하면 개선 미확인. 사용자가 정식 활성화 여부를 결정하기 전 기본 OFF로 종료한다. 원문/사례별 결과/키는 저장소 밖; PR에는 집계와 유형만 게시한다.

온라인 서면9 기존 회귀 점검·Drive 실제 표 색인/일반 캐시 확인도 함께 수행하되, 공개 개발 자료 점수와 새로운 법률 품질 비교는 구분한다. 다른 조건의 온라인 점수는 증감으로 비교하지 않는다.
