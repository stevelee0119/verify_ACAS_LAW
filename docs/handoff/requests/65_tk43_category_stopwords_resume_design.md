# TK-43 재개: 범주별 인명 후보 불용어 보충 설계

- 기준: Steve `0bf4ccc`; 사용자 통합 지시 (11), 평가 측 티켓의 「재개(2026-10-10)」(PR #61 브랜치). 성명 자동 마스킹 동결 해제는 TK-43에만 적용한다.
- 방법: 기존 인명 후보 불용어를 **절차·신청/증빙 서류, 재산·금융/조세, 신원·가족/생활, 근로·업무/정보관리** 범주로 보충한다. 각 범주의 정의·공개 법령/서식 출처를 목록 머리에 기록하고, 보호 시험이나 비공개 입력에서 낱말을 추출하지 않는다. 기존 목록과 신규 목록의 차집합을 범주별 낱말 수로 보고한다. 새 의존성은 쓰지 않는다.
- 판정 범위: 신규 목록은 **완전한 후보 일치에만** 적용한다. 기존 목록의 조사 1회 분리는 그대로 두되 신규 항목을 조사 분리 stem까지 넓히지 않는다. 접두어 제외, 조사 재귀 분리, 후행 낱말에 따른 제외, 성명 라벨/구조화 키 확대는 하지 않는다. 명시 성명 표지는 신규 목록으로 제외하지 않으며 탐지·마스킹·전송 전 검사 공유 경로를 유지한다.
- 일반화 근거: 법령의 재산·소득·가족관계·급여·절차와 공개 서식의 기재/증빙 항목은 사람 이름과 별개인 한정된 명사 범주다. 보호 시험의 명사만 보충하는 방법 대신 범주 전체의 기본 명사·문서 항목을 함께 다룬다. 법령 번호·문장·당사자에 따른 판정은 넣지 않는다.
- 위험: 일반 명사와 실명이 같은 철자이면 어휘만으로 완벽하게 구별할 수 없다. 불용어 접두부 뒤에 이름 음절이 이어지는 경우를 배제하지 않고, 조사처럼 보이는 이름 끝 음절도 떼어 새 불용어로 배제하지 않는다. 일반 명사+조사로도 읽히는 이름 후보의 과마스킹은 남긴다. 명확한 불용어에 해당하지 않는 후보는 마스킹한다. 새 항목 때문에 보호되어 있던 실명이 누락되면 해당 추가를 수용하지 않는다.
- 시험: 합성 범주별 정상 명사 3건 이상과 같은 접두부를 가진 이름 3건 이상을 같은 커밋에서 검사한다. 붙임/띄어쓴 이름·조사·콜론/전각콜론·기존/추가 라벨 및 PIIEngine 마스킹→inspect_request 경로를 함께 검사한다. 반복 입력 수천 건의 시간 시험을 둔다. 관련 개인정보·연락처/RRN 및 R6/R7 보호 시험만 실행하고 scorecard 전후·check_test_edits 원문을 제출한다. verify_all·비공개 과마스킹/유출·봉인 판정은 평가 측에 맡긴다.
