## 요구
정규식을 더하지 않는다(그러면 다음 변형이 또 새 낱말로 온다). 구조를 잡거나 TK-09의 "모델 제안 → 결정적 검증" 경로로 푼다. 예:
- 인젝션: 문서 본문 밖에서 검증 결과·등급·통과 여부를 정하려는 형식(구분자 문자 종류와 무관한 머리표·주석 + 대문자 식별자 + 통과·면제·우회 의미의 어휘군 + 문서 경계 위치). 구분자(`[ ]`, `<< >>`, `{{ }}`, `[[ ]]`)를 한 가지로 고정하지 않는다.
- 처분시법: 서면 내부에서 (1) 처분·행위 기준일, (2) 개정·시행·공포 날짜 + 법령명, (3) "적용하라/적용하여야/적용했어야" 류 적용 주장을 따로 뽑아 날짜 선후로 판단한다. 개정 동사(공포·시행·개정·신설)와 문장 순서는 선택 사항이다.
- 무리한 주장: 위법성 조각·책임 면제 사유(정당행위·긴급피난·정당방위·사무관리 등) 용어군 + 비위 사실을 다투지 않는 서술 + 요건 일부만 주장·소명하는 구조.

## 추가 증거: 처음 받은 서면8(2026가합48192)에서 같은 세 갈래가 그대로 재발했다
