# TK-05 규칙 부족: 공금 유용에 사무관리·정당행위 원용
- 유형: 규칙 부족(정규식 규칙이 사건 문구에 묶임) · 기준 커밋: 4ad64a7 · 작성: evaluator 2026-09-30

## 증상·증거
- 서면7은 예산 350만 원을 사적 식대·친목비로 쓴 비위에 대해 `민법 제734조의 사무관리`와 `형법 제20조의 정당행위`로 위법성이 조각된다고 주장한다. 오프라인·온라인 모두 이를 무리한 주장으로 알리지 않는다(서면7 LEG-1·2 실패).
- 사용자 온라인 보고서: `argument_validity_summary`는 "근거와 모순되는 항목 0건, 추가 확인 필요 3건(공식 DB에서 확인되지 않은 인용)". `case_applicability_reviews`의 정당행위 인용은 "주장과 조문 본문의 핵심어 겹침 0.25 — 자동으로 판단하지 않았다(사람 확인)". **모델 3개는 인용 미확인 건에만 의견을 냈고, 사무관리·정당행위 주장의 타당성은 묻지 않았다.**
- `config/legal_rules/rules.json`의 `CRIM.JUSTIFIABLE_ACT_PARTIAL_REQUIREMENTS`는 서면6의 문장 틀(`법익 균형성…충족…위법성 조각`, `정당행위에 해당하므로…`)에 맞춘 정규식이다. 서면7은 `context`(`정당행위|형법 제20조|사회상규`)는 충족하지만 `pattern`은 일치하지 않는다(`사회통념상 허용되는 정당행위이므로 위법성이 조각되어`: `정당행위(에|로) 해당…` 틀이 아님, 평가 측 확인). 서면6용 규칙을 서면7이 비켜 간 것이다.

## 수용 기준
- 서면7 LEG-1·2 통과(pdf·text, 판정은 SUSPICIOUS·사람 확인 대상 가능): `LEGAL_ARGUMENT_INVALID` 또는 `OVERCLAIM`, 본문에 `사무관리`/`734`, `정당행위` 포함.
- 정규식 규칙을 더 늘리는 방식으로는 닫히지 않는다. 문장 틀이 아니라 **구조**(비위 사실 인정 + 예외 사유 원용 + 요건 일부 생략)를 잡거나, TK-09의 모델 제안 → 결정적 검증 경로로 푼다.
- 양성 3건 이상은 주제(사무관리·긴급피난·정당방위 등)와 문장 틀이 서로 다른 합성 문서로, 대조군 3건 이상(요건을 모두 주장·소명한 서면, 판례를 정확히 인용한 서면)은 알리지 않는다.
