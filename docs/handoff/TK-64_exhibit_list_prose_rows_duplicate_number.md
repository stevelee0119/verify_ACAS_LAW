# TK-64 본문 서술 문단을 증거 목록 행으로 읽어 '같은 호증 번호 중복' A등급 오탐 (P2, 탐지, 기존 결함)
- 유형: 탐지 결함(P2). **회귀가 아니다.** 운영본(`main` 9192b44)에도 있다. A등급 오탐이라 우선순위를 높게 둔다.
- 발견: 평가 측, 은퇴 봉인 세트 `sealed_20261008b`를 개발용으로 옮긴 뒤 봉인 채점의 오탐 1건을 조사(2026-10-09).
- 작성: evaluator 2026-10-09

## 1. 증상
- `sealed_20261008b`의 SD-04에서 `EVIDENCE_LIST_MISMATCH`(rule `EVI.EVIDENCE_NUMBER_DUPLICATE`)가 A등급으로 나온다. 판정 문구는 '같은 호증 번호가 두 번 쓰였다: 을 제2호증'이다.
- 실제로는 같은 증거(을 제2호증)를 세 곳에서 언급했을 뿐이다.
  - 본문의 증거 설명 문단
  - 그 증거의 별지를 설명하는 문단
  - '다. 입증방법' 아래의 정식 목록
- 이 오탐이 문서의 FP-TRAP과 겹쳐 봉인 채점에서 오탐 1(A등급 1)로 집계됐다. 운영본과 TK-63 후보 모두 24.6으로 같다.

## 2. 원인 (`packages/claim_engine/evidence_consistency.py`)
1. **번호가 붙은 입증방법 제목을 구역 시작으로 알아보지 못한다.**
   - `_EXHIBIT_SECTION_HEAD_RE`는 줄 첫머리가 '입증방법·첨부서류·증거목록·소명방법'일 때만 맞는다.
   - '다. 입증방법', '3. 입증방법', '(1) 입증방법'처럼 앞에 번호가 붙으면 구역으로 보지 않는다. 그래서 그 아래의 정식 목록도 '본문' 규칙으로 읽힌다.
2. **본문 구역에서 서술 문단을 목록 행으로 받아들인다.**
   - `_exhibit_lines`는 본문 구역에서 문단 첫머리가 호증 번호이고 날짜가 있으면 목록 행으로 받는다.
   - 서술문 판별은 '하였다·바와 같이·살피건대·주장한다' 같은 해라체 몇 개뿐이다. 그래서 '을 제2호증은 … 부분입니다', '을 제2호증 별지의 … 입니다' 같은 합쇼체 서술 문단이 행이 된다.
3. 그 결과 같은 번호의 행이 셋이 되고, 행마다 '서증명'(사실은 서술 문장)이 달라 `_numbering`이 '서로 다른 증거에 같은 번호'로 확정한다.

## 4. 요구
1. 입증방법 등 목록 구역 제목은 앞의 번호(아라비아 숫자, 한글 가나다, 괄호 번호)가 붙어도 알아본다. 제목 뒤에 다른 말이 이어지는 문장('3. 내부 기준과 입증방법')은 구역 제목으로 보지 않는다.
2. 본문 구역에서 서술 문단을 목록 행으로 받지 않는다.
   - 해라체 어휘 목록을 늘리는 방식이 아니라, 문장 구조로 판별한다. 예: 호증 번호 바로 뒤의 주제 조사 '은/는', 문장 종결 어미('-다.'로 끝나는 문장 2개 이상).
   - 같은 서면에 목록 구역이 있으면, 같은 번호에 대한 본문 언급은 중복 판단에서 뺀다.
3. 시험(합성 입력, 시험 설명에 합성임을 적는다)
   - 양성 유지: 목록 구역 안에서 같은 번호를 서로 다른 증거에 붙인 경우는 계속 A등급으로 잡는다. 번호 앞 접두 유무별로 3건 이상.
   - 오탐 제거: 본문 서술 문단(합쇼체·해라체)과 번호 붙은 입증방법 목록이 함께 있는 서면에서 중복 판정이 나오지 않는다. 3건 이상.
   - 은퇴 세트의 문장이나 사건 값을 시험·규칙에 넣지 않는다. 형식만 같은 합성 입력을 쓴다.
4. 은퇴 세트 SD-04에 맞춘 규칙(특정 낱말·번호)을 넣지 않는다.
