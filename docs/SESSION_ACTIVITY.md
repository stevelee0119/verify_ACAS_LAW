# 장시간 검증과 로그인 유지

## 기본 정책

- 일반 비밀번호 로그인: 미사용 24시간, 최초 로그인부터 최대 168시간(7일). 분석 보호가 있으면 아래 작업별 정책이 우선한다.
- 인증·권한 확인에 성공한 브라우저 요청이 만료 시간을 연장한다. 분석 진행 상태 자동 조회도 포함한다.
- 만료 시각 갱신은 15분 단위로 제한하여 초당 반복 조회가 DB 쓰기로 이어지지 않게 한다.
- 검증을 접수할 때 현재 로그인과 검증 ID를 서버 DB의 `analysis_session_leases`에 연결한다. 재시도 작업에도 연결하며, 기존 진행 작업을 다시 조회하는 화면은 인증된 POST 요청으로 현재 로그인을 연결한다.
- 대기·분석 중에는 화면 조회나 브라우저 타이머 없이도 작업별 보호가 적용된다. 기본 상한은 **검증 시작부터 168시간**이며, 재조회로 상한이 계속 늘어나지 않는다.
- 정상 완료·부분 완료·실패·취소로 종료되면 종료 시각부터 **24시간** 동안 결과 확인을 허용한다. 늦게 종료되어 이미 분석 보호 상한을 넘긴 작업은 만료된 로그인을 되살리지 않는다.
- 보호는 연결된 로그인에만 적용한다. 같은 계정의 다른 로그인, 다른 사건에 접근할 수 없는 사용자에게 전파하지 않는다. 여러 작업 중 하나가 종료돼도 다른 진행 작업의 보호는 유지한다.
- HttpOnly 쿠키의 보관 기한은 서버의 미사용 기한과 분리한다. 쿠키가 남아 있다는 이유로 접근을 허용하지 않으며, 서버에서 일반 세션 또는 유효한 분석 보호를 매번 확인한다. 응답마다 쿠키 보관 기한을 재전달해 이전 응답 유실·다중 탭의 쿠키/DB 기한 불일치를 보완한다.
- 로그아웃, 비밀번호 변경, 계정 비활성화, 자격증명 폐기는 즉시 적용한다. 사건 접근 권한이 없어진 경우 해당 사건의 보호도 무효다. 보호 정보가 없는 만료 세션은 복구하지 않는다.
- 개인 접속 토큰의 브라우저 세션은 원본 토큰의 유효기간을 넘지 않는다. SSO는 제공자가 검증한 토큰의 만료를 임의로 연장하지 않는다.
- 자동 조회 중 인증이 만료되면 조회를 멈추고 `다시 로그인`을 표시한다. 로그인 후 기존 검증 ID의 상태·결과를 조회하며 새 검증을 만들지 않는다.

## 설정과 배포

| 환경변수 | 기본값 | 의미 |
| --- | --- | --- |
| `LV_SESSION_TTL_HOURS` | `24` | 브라우저 미사용 제한(시간) |
| `LV_SESSION_ABSOLUTE_HOURS` | `168` | 최초 발급부터의 상한(시간) |
| `LV_ANALYSIS_SESSION_HOURS` | `168` | 검증 시작부터 분석 보호 상한(시간) |
| `LV_ANALYSIS_RESULT_HOURS` | `24` | 분석 종료 후 결과 확인 유예(시간) |

각 값은 1~720시간이다. 일반 세션의 실제 만료는 미사용 제한과 최초 발급 상한 중 이른 시각이며, 유효한 분석 보호가 있으면 그 보호 기한까지 허용한다. 토큰·SSO의 원본 자격증명 기한은 이 예외로 늘리지 않는다.
기존 Render 서비스에 `LV_SESSION_TTL_HOURS=12`가 저장되어 있다면 그 값을 유지하면서 **12시간 고정 만료가 아닌 자동 연장 방식**으로 작동한다.
미사용 제한까지 24시간으로 바꾸려면 Render Environment의 기존 값을 `24`로 변경하고 재배포한다. 저장된 환경변수는 저장소의 `render.yaml` 수정만으로 바뀌지 않을 수 있다.

세션은 DB에 저장된다. 재배포 때 임시 SQLite DB가 사라지거나 DB가 교체되면 유효한 로그인도 유지할 수 없다. 영구 디스크의 SQLite 또는 영구 PostgreSQL을 사용해야 한다.
작업 보호가 일반 7일 상한을 넘을 수 있으므로 공용 기기에서는 작업 후 반드시 로그아웃한다. 이미 쿠키가 지워졌거나 보호가 없는 상태에서 만료된 로그인은 처음 한 번 다시 로그인해야 한다.

배포 시 `alembic upgrade head`로 `b83f21` 리비전을 적용한다. 기존 사용자·비밀번호·세션은 변경하지 않고 보호 테이블만 추가한다. 보호 이력을 유실시키는 다운그레이드는 거부한다.

## 회귀 검증

- 기존 12시간 설정에서도 분석 조회가 세션과 HttpOnly 쿠키를 함께 갱신한다.
- 분석 보호가 없을 때 반복 조회 중 최초 발급 상한은 연장되지 않는다.
- 일반 만료 시각을 지난 이틀 동안 조회가 없어도 진행 작업 및 결과를 확인할 수 있다. 종료 후 유예가 끝나면 만료된다.
- 보호 중 로그아웃·계정 중지·권한 회수와 다른 로그인/다른 조직 격리를 검증한다.
- 보호가 없는 만료 세션·폐기된 자격증명·비활성 계정, 잘못된 출처의 요청, 권한 거부, 일반 Bearer API 조회는 미사용 기한을 연장하지 않는다.
- 비밀번호·토큰·SSO의 원본 자격증명 제한과 로그아웃의 쿠키 삭제를 유지한다.
- 화면에서 401 반복 로그인, 늦게 도착한 401, 로그인 취소, 로그인 후 기존 결과 재조회 및 모바일 배치를 검증한다.
