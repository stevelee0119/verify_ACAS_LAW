# v3 변경 기록

작업 지시서: `claude_code_prompt_verifier_v3.md`(D1~D9, 일반 견고성 보강)와 추가 지시(G1~G7).
프로그램 버전(`packages/common/config.py`의 `version`)은 푸시할 때마다 올린다.

## 0.6.0

| 항목 | 수정 | 시험 |
|---|---|---|
| D1 변형 인용문 | `quote_diff`: 최대 유사 구간(0.85 이상 1.0 미만)을 어절 경계까지 넓혀 삭제·추가·치환 어절을 원문과 나란히 제시(`render_quote_diff`). 정도 부사·부정·양태·조문 한정어(단서·본문·제N항)·수량이 바뀌면 CONTRADICTED(A), 그 밖의 표현 차이는 SUSPICIOUS(B). 말줄임표로 표시한 생략은 구간별 대조, 어미 1~2자 차이는 제외. 한 인용의 결함이 여럿이면 최종 판정 제목에 모두 표시. AI 교차검토 요청에 원문 대조 결과를 넣고 원문 기준 평가를 지시 | `test_v3_d1_quote_diff.py` |
| D3 의견 귀속·결론 방향 | `opinion_attribution`: 판결 전문("…의 반대의견은 다음과 같다")과 판결요지("[다수의견]", "[대법관 …의 반대의견]")를 의견 구간으로 나누고, 서면 요약이 반대의견에 뚜렷이 가까우면 MISATTRIBUTED_OPINION(반대의견에만 있는 문장을 직접 인용하면 A). 판시사항의 "…인지 여부(적극/소극/원칙적 소극)"와 반대 방향으로 단정하면 HOLDING_DIRECTION_REVERSED | `test_v3_d3_opinion.py` |
| D2 법원–사건부호 | 사건부호표 `config/legal_rules/case_codes.yaml`을 공식 별표(재판예규 제1812호, 국가법령정보센터 행정규칙 ID 2200000102523, 별표 HWP 2개)에서 `scripts/build_case_codes.py`로 생성(127개 부호). 부호→사건 유형(원문)→심급(상고·재항고·특별항고 = 대법원, 항소·항고·1심 = 하급법원, 그 밖 = 판단 안 함). 법원 종류(대법원·헌법재판소·하급법원)가 부호와 다르면 COURT_CODE_MISMATCH(A), 대법원 '누'는 1998년까지 허용·1999년 판단 안 함·2000년 이후 사용 기간 밖. 조회에 실패하면 부호가 가리키는 법원 DB로 재조회해 "법원 표시 오류(실제: 대법원 판결)"를 적는다. 인용 표기에서 법원명 뒤 조사 제거 | `test_v3_d2_case_codes.py`, `test_v3_d2_build_codes.py` |
| D5 제목 | INVALID_FORMAT 제목을 위반 유형별로: 날짜 불가능 / 법원–부호 불일치 / 연도 역전·연도 불가능 | 기존 시험 2건 기대값 갱신 |
| HWP 표 | `_extract_hwp_tables`: 표를 셀(행·열 주소) 단위로 복원 | `test_hwp_parser.py` |

경로 차이: 지시서는 `data/case_codes.yaml`을 요구했으나 `data/`는 실행 데이터 폴더(LV_DATA_DIR, git·Docker 이미지 제외)라
배포본에 들어가지 않는다. 참조 데이터는 배포되는 `config/legal_rules/`에 둔다.

사건부호표 범위: 국가법령정보센터가 제공하는 별표 파일 2개에는 민사·형사 일반 사건부호(가합·다·도 등, 별표 첫 부분)가 없다.
그 부호는 표에 넣지 않았고 판단하지 않는다(unknown).
